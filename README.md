# DrivingSchoolSim

Проект учебного автосимулятора для Windows. Есть модель автомобиля, визуальная демонстрация, учебный автодром, UI и архитектурный каркас. Полноценная физика вождения, G27 force feedback, PCVR и город 10 × 10 км ещё не реализованы.

**Учебная площадка (v4):** сцена `Assets/DrivingSchool/Scenes/Autodrome_Training.unity`
собрана по схеме автодрома 100 × 100 м (`docs/autodrome-schema-100m.png`). Каждое
упражнение (У2–У10) есть в одном экземпляре. Они соединены сквозным маршрутом по дорогам
схемы: Старт → У2 → У6 → У3 → У8 → У7 → У5 → У10 → У9 → У4 → Финиш. Доступны
отдельные уроки, экзамен по всему маршруту и тестовое вождение с клавиатуры.
Это прототип с упрощённой кинематикой, а не готовый физический симулятор.
[План площадки, условия уроков и запуск](docs/training-ground.md).

Зафиксированная версия редактора: Unity **6000.3.10f1**. В `Packages/manifest.json`: URP 17.3.0, Input System 1.18.0, uGUI 2.0.0, OpenXR 1.16.1, XR Management 4.5.4, Test Framework 1.6.0. Наличие пакета не доказывает рабочую интеграцию; TMP и XR требуют отдельной проверки ресурсов и настроек. Демонстратор использует IMGUI.

1. [Требования и трассировка](docs/requirements.md) — обязательный результат, задачи и критерии приёмки.

3. [Архитектура](docs/architecture.md) и [решения ADR](docs/adr.md) — границы модулей и проектные решения.
4. [Форматы данных](docs/data-formats.md) — точные текущие контракты и порядок расширения.
5. [Стандарт ассетов](docs/asset-standard.md) — автомобиль, окружение, импорт и целевые бюджеты.
6. [Приёмка и команды](docs/acceptance.md) — воспроизводимые проверки без неподтверждённых PASS.
7. [План реализации](docs/implementation-plan.md) — порядок этапов, зависимости и условия перехода.
8. [Малые задания](docs/tasks/README.md) — отдельные карточки для кодовых исполнителей с небольшим контекстом.

Исходники находятся в `Assets/DrivingSchool/Code`, примеры данных — `Assets/StreamingAssets/Examples`, исходники моделей — `ArtSource`, экспорт/визуальные доказательства — в каталогах артефактов. Точные существующие пути и несовпадение с целевым `Art/Exports` указаны в стандарте ассетов.

Для открытия выберите эту папку как проект Unity. До запуска подготовки прочитайте [команды C00–C04](docs/acceptance.md#команды): `ProjectBuilder.Prepare` изменяет сцены и настройки, а `tools/setup_project.py` перезаписывает каркас и демонстрационные данные. Не запускайте генератор как безвредную проверку проекта.

Пакет основан на чтении исходников 18.09.2026 и обновлён 19.09.2026: Unity compile завершился с exit0; узкое исправление оболочки модели принято по отдельным отчётам. NUnit, готовая Windows-сборка, G27, VR, FPS и полный ход колёс этим не подтверждены. Точные границы и артефакты см. в [текущем состоянии](docs/current-state.md). Файлы старых отчётов и слово PASS внутри них сами по себе не являются приёмкой текущего ассета.
