# Отчёт визуальной проверки интерфейса (QA Report)

## 1. Обзор проверки

Автоматизированная проверка выполнена с помощью Playwright (`qa-capture.cjs`) и Microsoft Edge headless в двух целевых разрешениях:
- **1920 × 1080** (Full HD — целевое десктопное разрешение)
- **1280 × 720** (HD Ready — минимальное поддерживаемое разрешение)

Скрипт проверял:
1. Отсутствие горизонтального переполнения (`scrollWidth > innerWidth`).
2. Целостность всех медиа-ресурсов (отсутствие битых изображений `naturalWidth === 0`).
3. Полноту интерактивных переходов между экранами.
4. Корректность отображения критических состояний (ошибка отключенного устройства, выбор неверного ответа, dirty-state редактора).
5. Доступность клавиатурного фокуса (`Tab navigation` и outline-стили).

## 3. Проверка интерактивных сценариев и пограничных состояний

- **Сквозная навигация:**
  - `home → lessons → vehicle → drive → pause → result` выполняется бесшовно через клиентский роутинг по `#hash`.
- **Выбор условий:**
  - Переключение времени суток (День / Ночь) обновляет предпросмотр автомобиля и HUD на ночной рендер салона с подсветкой приборов.
  - Переключение КПП (МКПП 5-ступ. / АКПП) обновляет параметры и информационную карточку.
- **Калибровка G27 (отрицательный сценарий и сохранение):**
  - При попытке сохранить профиль с отключенным устройством отображается явная ошибка: `Ошибка: сначала включите виртуальную калибровку`.
  - После включения виртуального режима ползунки осей и руля обновляют живые значения (угол от −450° до +450°, педали 0–100%). Сохранение переводит профиль в статус `сохранён`.
- **Теория ПДД:**
  - Нажатие «Проверить ответ» без выбора варианта вызывает всплывающее предупреждение: `Выберите один из ответов`.
  - Неверный ответ подсвечивается красным с объяснением ошибки.
  - Верный ответ подсвечивается зеленым с подтверждением и обучающим комментарием.
- **Редактор города:**
  - Клик по схеме генплана 10 × 10 км размещает выбранный маркер (`Дорога`, `Здание`, `Знак`, `Растительность`).
  - Появляется статус несохраненных изменений `● Есть несохранённые изменения`.
  - Экспорт генерирует валидный JSON с исходным генпланом и добавленными маркерами.
  - Кнопка `↶ Отменить` корректно снимает последний маркер.
- **VR Layout:**
  - Подготовлены крупноформатные панели для шлема с безопасным расстоянием до глаз, крупными кнопками и отсутствием визуального шума.
- **Клавиатурная доступность:**
  - Все интерактивные элементы имеют `focus-visible` стиль с контрастным синим контуром (`outline: 3px solid #8ebfe1`).

## 5. Границы и ограничения прототипа

1. HTML-прототип является **визуальной и интерактивной спецификацией** дизайн-системы (токены, цвета, сетка, типографика, компоновка).
2. Прототип **не читает физические устройства** Logitech G27 по DirectInput / HID и не выдаёт Force Feedback.
3. Прототип **не симулирует физику автомобиля**, поведение шин или дорожные контакты.
4. Перенос экранов в uGUI/TextMeshPro выполняется по готовым карточкам (начиная с `T03`).
