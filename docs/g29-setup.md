# G29: подключение и калибровка

1. Подключить G29 по USB в PC-режиме, шифтер — к рулю. Windows и Unity должны видеть USB `046D:C24F` ([спецификация Logitech](https://support.logi.com/hc/en-au/articles/360023463753-G29-Driving-Force-Racing-Wheel-Technical-Specifications)). Игра не выбирает устройство только по слову «Wheel» в названии.
2. В настройках управления открыть «Калибровка руля и педалей». Поочерёдно назначить руль, газ, тормоз и сцепление: нажать строку, затем сдвинуть нужную ось. Каждую ось провести в оба упора, руль вернуть в центр и нажать «Центр». При необходимости включить индивидуальную инверсию.
3. Для МКПП назначить R и 1–6: нажать строку, затем включить передачу рычагом. Если шифтер не назначен или отключён, неназначенная передача не включается; пустая схема H остаётся в нейтрали.
4. Сохранить калибровку и выбрать «Logitech G29» как устройство ввода. Фары, зажигание и остальные клавиатурные команды продолжают работать; их можно изменить в «Переназначение клавиш». Кнопки руля для меню и этих команд пока не калибруются.

Калибровка и клавиши хранятся в `settings.json` через обычный механизм настроек. При отключении руля газ сбрасывается и поездка ставится на паузу. При потере фокуса ввод машины блокируется.

Input System на Windows представляет HID-руль набором контролов; номера осей и кнопок зависят от дескриптора, поэтому их нужно снять с устройства, а не угадывать ([документация Unity HID](https://docs.unity.cn/Packages/com.unity.inputsystem%401.7/manual/HID.html)). FFB пока остаётся программным mock: Input System не предоставляет готовый бэкенд сил для G29. Для аппаратного FFB кандидат — [Logitech Steering Wheel SDK](https://www.logitechg.com/en-za/programs/partner-developer-lab); лицензию и доставку нативной библиотеки нужно проверить до включения в сборку.

## Проверка поворота

Полный ход G29 соответствует команде `steering = ±1`. У седана база 2,72 м и максимальный средний угол передних колёс 32°: геометрический радиус по центру задней оси `2,72 / tan(32°) ≈ 4,35 м`. Внутреннее переднее колесо поворачивается сильнее внешнего по Аккерману. Динамический радиус больше при скольжении; на высокой скорости удерживаемая клавиша руления ограничена по предполагаемому боковому ускорению, а физический руль использует полный ход. Для проверки на настоящем устройстве нужно сравнить угол в телеметрии полигона с положением руля и проехать круг на сухом асфальте при 5–10 км/ч.
