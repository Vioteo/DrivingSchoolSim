# Окружение — Environment Kit v1 (префикс `EN_`)

Набор моделей для загорода, леса, дворов и парковок: 56 ассетов. Всё строится одним воспроизводимым скриптом Blender `tools/build_env_kit.py` (генератор — пакет `tools/env_kit/`). Задача — [T73](tasks/T73.md).

Стиль — стилизованный, как у остальных наборов проекта: однотонные материалы из палитры, без текстур. Кроны деревьев — цельные «облака» из сгустков листвы (voxel remesh → шум → decimate), верхние грани светлее нижних.

### Загородная дорога (`road.py`)

Модули идут вдоль +Z Unity от `Socket_Start` (0,0,0) до `Socket_End`. Повороты — направо; левый поворот — тот же модуль, пройденный в обратную сторону.

Поперечник от оси: полоса 3,5 м | линия 1.2 и укреплённая полоса до 4,25 м (верх асфальта Y = 0) | гравийная обочина до 6,2 м (спад до −0,09) | откос 1:3 | кювет, дно −0,78 м | обратный откос | земля Y = 0 на 12,5 м. Ширина модуля 25 м. На асфальте — несколько «заплаток» другого цвета.

| Модель | Разметка по оси | Длина |
|---|---|---|
| `EN_Road_Country2_24m` | 1.5 (штрих 3 м, промежуток 9 м) | 24 м |
| `EN_Road_Country2_24m_Approach` | 1.6 линия приближения (6 / 2 м) | 24 м |
| `EN_Road_Country2_24m_Solid` | 1.1 сплошная | 24 м |
| `EN_Road_Country2_Curve90_R50` | 1.1, опасный поворот 90°, R 50 м по оси | дуга 78,5 м, выход (50, 0, 50) по +X |
| `EN_Road_Country2_Curve30_R160` | 1.5, плавный поворот 30°, R 160 м | дуга 83,8 м |

Коллизия — `COL_DriveSurface` (весь поперечник, включая кюветы). Разметка — отдельный дочерний меш `*_Markings`, поднят на 5 мм.

### Отбойники (`barrier.py`)

Барьерное ограждение — W-балка в духе группы 11ДО: балка 310 мм, верх 0,75 м, стойки-швеллеры через 2 м, консоли-амортизаторы, стык балок с болтами, световозвращатели на консолях. Секция идёт вдоль +Z Unity от `Socket_Start` к `Socket_End` по линии стоек, **дорога — слева (−X)**. Для левой кромки дороги секцию разворачивают на 180°.

## Что стилизовано (не нормативно)

- Пиктограммы знаков 1.11, 1.34, 3.20 нарисованы «от руки»: форма, цвета и типоразмер — по ГОСТ Р 52290-2004, но рисунок **не сверен** с чертежами стандарта. Пропорции щита 1.34 — игровые.
- Разметка: ширины и длины штрихов взяты из ГОСТ Р 51256-2018 (1.5 — 3/9 м, 1.6 — 6/2 м), но с текстом стандарта **не сверены** построчно.
- Барьерное ограждение — «в духе» 11ДО (ГОСТ Р 52607 / ГОСТ 33128): высота и шаг стоек типичные, профиль балки упрощён.
- Поперечник загородной дороги, глубина кювета, размеры площадок и дворового оборудования — типичные значения, не по СП.
- Асфальт без поперечного уклона (Y = 0), чтобы стыковаться с городскими модулями.

## Файлы

- Генератор: `tools/env_kit/` — `core.py` (построитель сеток в «авторской» системе X вправо / Y вперёд / Z вверх, разворот в систему Blender, LOD, крона `organic`), `materials.py` (палитра), `forest.py`, `road.py`, `barrier.py`, `yard.py`, `parking.py`, `checks.py`, `review.py` и `review_more.py` (сцены для рендеров).
- Blender: `tools/build_env_kit.py`, `tools/build_env_kit.bat`.
- Исходник: `ArtSource/DS_EnvKit.blend` — каждый ассет в своей коллекции (исключены из слоя вида, стоят в начале координат); сцены `Review_*` собраны из экземпляров коллекций.
- Unity: `Assets/DrivingSchool/Art/EnvKit/EN_*.fbx`, палитра `EN_Materials.json`. Настройки импорта — `Code/Editor/EnvKitImportSettings.cs` (масштаб 1, `bakeAxisConversion`, без камер и света; у деревьев без второго UV).
- Оси после импорта (проверено в Unity 04.10): параметры экспорта — из `art-pipeline.md` §4 (`bake_space_transform` не включаем: он ломает вложенные пивоты, например стрелу шлагбаума). Корень FBX-модели несёт поворот осей, масштаб в метрах. **Лицевая сторона сырого FBX смотрит в −Z** (как и у набора транспорта при параметрах экспорта из `art-pipeline.md` §4). У каждого ассета есть `Socket_Front` (1 м вперёд) и `Socket_Up` (1 м вверх) — сборщик набора разворачивает дочерний `Model` по ним, как `TransitKitBuilder`.
- Отчёт: `artifacts/reports/envkit-manifest.json` (SHA256, габариты, треугольники по LOD, сокеты, проверки). Рендеры: `artifacts/visual-review/envkit/`.

## Как пересобрать

```powershell
tools\build_env_kit.bat                 # всё: модели, FBX, рендеры (Blender 5.0, ~5 мин с GPU)
# или: blender -b --factory-startup --python-exit-code 1 --python tools/build_env_kit.py -- --no-render
#      ключи: --fast (быстрые рендеры), --only forest,road,barrier,yard,parking, --no-export, --shots a,b
```
Скрипт падает с exit 1, если не прошла хоть одна проверка `checks.py`: корень без трансформаций, ничего не уходит под землю глубже допуска, бюджеты треугольников, каждый LOD ≤ 60 % предыдущего, габариты, сокеты на месте, есть `COL_*`, повторный импорт FBX даёт те же габариты.

В рендерах для масштаба использованы машины трафика и дом `DS_House_Brick5` проекта — они не входят в набор и не экспортируются.

## Ограничения и следующие шаги

- **Нет Unity-сборщика набора**: префабов (корень + `Model`), URP-материалов из `EN_Materials.json`, LODGroup, коллайдеров из `COL_*`, демо-сцены. Сейчас FBX только импортируются с правильными настройками. Это следующий шаг вместе с расстановкой.
- **Расстановка в мире не сделана**: загородная трасса с опасным поворотом и лесом, дворы у домов района, парковки — следующий шаг (генератор сцены).
- Прямые секции отбойника по дуге другого радиуса дают изломы; для поворотов других радиусов нужны свои дуговые секции или генератор, протягивающий профиль по пути.
- Нет текстур (кора, асфальт, трава) — только цвета палитры; UV планарные в метрах, текстуры можно добавить позже.
- Знаков 1.12 (опасные повороты), 8.х и разметки 1.24 (инвалиды) нет.
