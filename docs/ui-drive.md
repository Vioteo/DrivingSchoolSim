Статус: **проект, на согласовании** (24.09.2026). Код по документу не написан.
Макет: `artifacts/visual-review/drive/index.html` (сводка всех экранов — `screens.png`). Тема «Асфальт», шрифт — рекомендованная пара Golos Text + Roboto Mono (`docs/ui-settings.md` §6, §8).

## 1. Зоны HUD (кадр 1920×1080)

Правка владельца 24.09: HUD — только то, что нужно водителю сейчас. Убраны: панель знаков в зоне действия, подсказки клавиш, ряд полос в навигаторе, дистанция и знак ограничения в приборах, подробности у штрафных баллов.

| Зона | Элемент | Полный | Минимальный | Выкл. |
|---|---|---|---|---|
| Слева вверху | Навигатор: одна стрелка манёвра, расстояние, улица | ✓ | ✓ | — |
| Сверху по центру | Подсказка инструктора | ✓ | ✓ | ✓ (если `instructorHints` ≠ Выкл.) |
| Справа вверху | Штрафные баллы: число + 7 сегментов, последний — прекращение | ✓ | ✓ | ✓ |
| Справа, под баллами | Карточки нарушений (не больше 2, 7 с) | ✓ | ✓ | ✓ |
| Слева внизу | Мини-карта, север вверху, масштаб | ✓ | — | — |
| Снизу по центру | Приборы: контрольные лампы, скорость, схема КПП, полоса оборотов | ✓ | скорость + схема КПП | — |

- **Скорость** краснеет при превышении текущего ограничения. Самого знака в HUD нет: ограничение видно на дороге.
- **Передача — графически**: схема H-паттерна текущего автомобиля, включённая передача подсвечена акцентом, нейтраль — точка в центре, R — красной цифрой. Раскладка (число передач, место R) берётся из данных автомобиля, не зашивается в UI. Для АКПП — строка P R N D с подсвеченным положением.
- **Нарушения и прекращение экзамена показываются всегда**, в любом режиме HUD: это обратная связь обучения, а не украшение.
- Подсказок клавиш в поездке нет. Управление описано в меню паузы и настройках.
- Масштаб всего HUD — `gameplay.uiScale`. Отступ от края кадра — 40 px на 1920, чтобы HUD не резался на ТВ с overscan и в VR.
- Вид из салона: реальная приборная панель модели уже показывает скорость и обороты, поэтому по умолчанию HUD-приборы скрываются (макет «Автодром»). Настройка — после появления вида из салона.

## 2. Подсказки инструктора

Одна видимая подсказка, остальные в очереди («ещё N в очереди»). Цвет полосы — тип:

| Приоритет | Тип | Цвет | Пример | Время |
|---|---|---|---|---|
| 1 | Безопасность (пешеход, красный, помеха) | красный | «Пешеход на переходе справа…» | пока есть угроза |
| 2 | Подготовка к манёвру | акцент темы | «Перестройтесь в правый ряд заранее…» | до начала манёвра |
| 3 | Навигация | синий | «После поворота держитесь правого ряда…» | 8 с |
| 4 | Упражнение (автодром) | синий | «Следите, как заднее колесо проходит угол бокса…» | до смены шага |

- Подсказка с более высоким приоритетом вытесняет текущую сразу; вытесненная возвращается в очередь, если ещё актуальна.
- `gameplay.instructorHints`: «Все» — все типы; «Только ошибки» — только замечания после нарушения; «Выкл.» — ничего, кроме карточек нарушений.
- Голос инструктора (звука пока нет) дублирует текст; `gameplay.subtitles` управляет текстом, когда звук появится.
- Ключи текстов — `explanationKey` из `RuleEvent` и ключи урока, а не строки в коде.

## 3. Нарушения ПДД

- Карточка: название, `ruleId`, баллы, одна строка «как правильно». Появляется справа, живёт 7 с, не больше двух на экране.
- Счётчик баллов: сегменты 1…7. Последний сегмент — порог прекращения. Режим «Тренировка» не прекращает поездку; режим «Экзамен» — прекращает.
- **Прекращение экзамена** (ошибка весом 7 или сумма выше порога): затемнение, причина, `ruleId`, кнопки «Разбор поездки» / «Повторить маршрут».
- **Веса и порог в макете — примеры по открытым источникам (аудит §5.2), не сверены** с методикой (приказ МВД России № 80 от 20.02.2021 с изменениями). Показывать игроку веса только из версионируемой таблицы ошибок с редакцией и источником (правило 5 CLAUDE.md). До этого UI помечает вес «не сверен».
- Идентификаторы в макете — текущие константы `TrafficRules`: `PDD_8.1_TURN_SIGNAL`, `PDD_6.2_RED_LIGHT`, `PDD_10.2_SPEED_LIMIT`, `PDD_6.13_STOP_LINE`, `AUTODROME_EXERCISE_BOUNDARY`. Реестр «пункт ПДД → шифр → вес → редакция» — задача правил, не UI.

## 4. Навигатор и карта

- Мини-карта: север вверху, маршрут — акцент, пройденное — серое, машина — белая стрелка по центру. Масштаб 100 м.
- Полноэкранная карта — по `M` в поездке, игра на паузе. Слева карта с маршрутом, упражнениями (синие точки) и местами нарушений (красные точки); справа список шагов маршрута с километражом.
- Экзаменационный маршрут с упражнениями на маршруте — по аудиту §5.1: разворот, параллельная парковка, остановка на подъёме в городском движении.
- **Данных пока нет:** маршруты и названия улиц требуют roadgraph v2 (T11) и экзаменационного маршрута. Макет показывает схему, а не реальный район `District`.

## 5. Разбор поездки

- Шапка: итог («Сдано» / «Не сдано») и сумма баллов, режим и маршрут.
- Слева — сводка: баллы, время, дистанция, упражнения, **использованные помощники** (ADR-007: помощники отражаются в результате).
- Центр — хронология событий (`SessionResult.events`), выбор стрелками.
- Справа — выбранное событие: что произошло, как правильно, `ruleId`, вес, редакция, `evidenceId`, место на схеме.
- Кнопки: «В меню», «Повторить тему» (переход в теорию по `topic`), «Пройти снова».
- Повтор момента (`Enter`) — только после появления записи поездки; до этого кнопка скрыта.

## 6. Теория

- Режим «Тренировка»: объяснение сразу после ответа, ответы клавишами `1`–`3`, прогресс квадратами (зелёный — верно, красный — ошибка).
- Режим «Экзамен»: без объяснений до конца. Число вопросов, время и допустимые ошибки берутся из методики с указанием редакции, в UI не зашиваются.
- Источник пакета показывается всегда. `isOfficial = false` → бейдж «Демо-вопрос · не официальный билет». В проекте сейчас один авторский вопрос (`StreamingAssets/Examples/theory.json`).
- Слот иллюстрации к вопросу предусмотреть (`TheoryQuestion` пока без поля картинки → при добавлении обновить `data-formats.md`).

## 7. Откуда берутся данные и чего не хватает

| Элемент | Источник | Есть сейчас? |
|---|---|---|
| Скорость, передача, обороты | `VehicleState.signedSpeedMps`, `gear`, `engineRpm` | да |
| Указатели, ближний/дальний свет | `VehicleState.leftIndicator/rightIndicator/lowBeam/highBeam` | поля есть; `DriverCommand` их не передаёт (аудит §7, этап 1) |
| Ремень, аварийка, стояночный тормоз | `DriverCommand.handbrake` есть; ремня и аварийки нет | частично |
| Ограничение (для красной скорости) | `RoadSegment.speedLimitKph` | да |
| Схема КПП | данные автомобиля (число передач, место R) | нет, нужно поле в описании автомобиля |
| Нарушения, баллы | `RuleEvent` (`ruleId`, `penalty`, `explanationKey`, `evidenceId`) | да; таблица весов не сверена |
| Шаги упражнения | `course-v2.json` → урок | названия да, шаги нет |
| Маршрут, улицы, полосы | roadgraph v2 | нет |
| Разбор | `SessionResult` (`events`, `enabledAssists`, `elapsedSeconds`) | да, кроме дистанции |

## 8. Управление в поездке (G29, предложение)

Меню — по `docs/ui-settings.md` §6. В поездке: OPTIONS — пауза, SHARE — карта, △ — камера. На экране эти кнопки не подписываются. Поворотники, свет, ремень и аварийка — после расширения `DriverCommand` (аудит §7, этап 1) и HID-раскладки G29 (T04).
