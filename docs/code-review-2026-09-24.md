## 4. Ошибки в коде

**Критичные (сломают будущую «честную машину» и правила):**
1. `Presentation/Physics/VehiclePhysicsAdapter.cs:170` — `Body.linearVelocity = transform.forward * speed` каждый шаг: руль не поворачивает машину, столкновения и боковое движение стираются.
2. `VehiclePhysicsAdapter.cs:188-190` — поворотники вычисляются из угла руля, ближний свет = зажигание. Правило «не включил поворотник» из-за этого никогда не сработает. Нужны поля в `DriverCommand`.
3. `VehiclePhysicsAdapter.cs:113` — нагрузка на двигатель `Math.Abs(clutchTorque)`: когда колёса крутят двигатель (торможение двигателем, накат), двигатель всё равно тормозится. `:119` — при заглохшем двигателе сцепление перестаёт передавать момент, т. е. заглохшая машина на передаче катится свободно.
4. Три несовместимые шкалы штрафов: `TrafficRules` (5/15/25/100), `SpeedLimitEvaluator` (500), `course-v2.json` (1–2, незачёт 5). Ни одна не совпадает с методикой ГИБДД (1/2/3/4/7). Нужна одна таблица-данные.

**Средние:**
5. `Rules/RuleEvaluator.cs` — состояние стоп-линии одно на весь оценщик: две стоп-линии подряд не обработать.
6. `Learning/TrainingCourse.cs:119` — логика отката на эстакаде включается по строке `id == "hill"`. Переименование урока молча выключит проверку; нужен флаг в данных урока.
7. `TrainingCourse.cs:109` — граница площадки по X считается от длины машины, а не ширины (перестраховка, но неочевидно).
8. Разные схемы клавиш: в `TrainingVehicle` E — передача 1/2, пробел — удержание ручника; в `KeyboardInputSource` E — стартер, пробел — переключение ручника. При замене машины игрок получит другие кнопки.
9. `Input/LogitechG27Adapter.cs:102,182` — по умолчанию симулированный ввод, «боевой» режим читает `Gamepad.current`. G27 — HID-руль, не геймпад: реальный руль не заработает.

**Стиль (не срочно):** местами код в одну строку без пробелов (`LessonSession`, `CourseSession`, `TrainingVehicle`) — трудно читать и ревьюить; IMGUI в игровой сцене.
