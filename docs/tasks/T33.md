# T33 — Проезд перекрёстков ИИ: приоритет и зоны конфликта (Junction Arbitration)

- **Требования:** R09.
- **Критерий приёмки:** A11.
- **ADR:** ADR-012. Дизайн: [city.md](../city.md#перекрёстки-t33).
- **Зависит от:** T16, T27, T31, T32, T35 (каркас диспетчера), T40 (запрос `EnterConflictZone` и таблица резервов).

## 1. Конкретный результат и зависимости

Pure C# `JunctionArbiter`: решает для агента у въезда на перекрёсток, можно ли занять зоны конфликта его связи.
- Порядок: сигнал (T32) → знаки приоритета (главная/второстепенная) → помеха справа на равнозначном → уступить встречным при повороте налево и развороте → уступить пешеходам на пересекаемом переходе. В данных каждого правила — пункт ПДД РФ (6.2, 13.4, 13.9, 13.11, 14.1 и др.) и редакция, сверенная исполнителем.
- Резервирование зон на время проезда с запасом; освобождение после выезда.
- «Не выезжать на перекрёсток при заторе» (п. 13.2 — сверить): въезд только если за перекрёстком есть место.
- Разрешение взаимной блокировки: граф ожиданий, цикл дольше порога → проезжает агент с наименьшим `id`. Помечено как игровое правило.
- Игрок участвует как обычный участник (через T31), но его решения не блокируются — ИИ только уступает ему по правилам или ради безопасности.

Таблица резервов живёт в диспетчере трафика ([T35](T35.md), ADR-014): агенты запрашивают зону, диспетчер выдаёт разрешение по правилам этой карточки.

## Реализация, ядро (24.09.2026)

`Simulation/Traffic/JunctionPolicy.cs`, используется диспетчером (T35): сигнал → приоритет въезда по знакам → левый поворот уступает встречным → помеха справа → кто раньше → id; развязка взаимной блокировки через `DeadlockSeconds` (игровое правило). Тесты: помеха справа, левый поворот, главная дорога, четыре машины на равнозначном, 40 случайных прогонов без пересечения резервов. Остаётся по карточке: «не выезжать на перекрёсток при заторе» проверяется упрощённо (занятое начало полосы выезда), сценарии T38 для всех пунктов ПДД с редакцией.

## 4. Примеры данных и ожидаемого поведения

- Равнозначный крест, две машины одновременно с юга и с востока, обе прямо: едет восточная (у южной помеха справа).
- Поворот налево на зелёный при встречной машине прямо: ждёт в перекрёстке, проезжает после неё.
- Съезд со второстепенной (2.4) при машине на главной с TTC 3 с: ждёт.

## 5. Отрицательные сценарии

- Четыре машины на равнозначном одновременно → не более заданного времени ожидания, затем проезд по разрешению блокировки, без взаимного проезда в одну зону.
- Две связи с общей зоной никогда не получают `Go` в одном тике (инвариант проверяется на 10 000 случайных seed).
- Затор за перекрёстком → `Yield` даже на зелёный.
