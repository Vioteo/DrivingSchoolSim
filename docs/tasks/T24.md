# T24 — Интеграция OpenXR и центрирование взгляда (OpenXR Tracking Gate)

- **Требования:** R01 (PC VR, OpenXR платформа), R15 (доказуемость).
- **Критерий приёмки:** A14 (PCVR gate criteria).
- **ADR:** ADR-009 (отдельные ворота качества для VR), ADR-001 (адаптеры).

## 1. Конкретный результат и зависимости

Разработать компонент интеграции с OpenXR `OpenXRTrackingGate` в сборке `DS.Presentation.XR`:
- Проверка доступности и инициализация OpenXR подсистемы через `XRGeneralSettings`.
- Привязка трекинга 6DoF (положение и ориентация головы в пространстве) к водительскому месту:
  - Базовая точка: `Socket_DriverEye` в иерархии префаба `DS_Sedan_A`.
  - Масштаб пространства строго 1:1 (SI метры).
- Реализация операции центрирования взгляда (**Recenter Pose**):
  - Вызывается по горячей клавише или кнопке руля.
  - Мгновенно совмещает текущее физическое положение шлема с точкой обзора водителя без накопления ошибки.
- Обработка жизненного цикла гарнитуры:
  - Снятие шлема с головы (`userPresence = false`): автоматическая постановка на паузу.
  - Потеря связи со шлемом (disconnect / runtime crash): безопасное переключение на десктопную камеру без завершения процесса симулятора.

## 3. Точные входы, выходы и контракты

- **Контракт интерфейса:**
  ```csharp
  public class OpenXRTrackingGate : MonoBehaviour
  {
      public bool IsXrActive { get; }
      public bool IsUserPresent { get; }
      public void RecenterDriverView();
      public void SwitchToDesktopFallback();
  }
  ```
- **Входы:** Действия трекинга позиции головы из Input System (`XRController` / `HMD`), целевой Transform водительского глаза.
- **Выходы:** Скорректированная матрица вида основной камеры.

## 4. Примеры данных и ожидаемого поведения

- Пользователь надел шлем и сел за стол:
  - Исходное положение головы смещено на 20 см влево и 10 см назад относительно сокета.
  - Нажатие кнопки центрирования (`RecenterDriverView`): виртуальная голова мгновенно занимает положение `Socket_DriverEye`, а угол обзора выравнивается строго по направлению движения автомобиля (вдоль оси Z вперед).

## 5. Отрицательные сценарии

- **Отсутствие подключенного шлема:** Если OpenXR runtime не запущен (обычный запуск на мониторе), компонент инициализируется в пассивном режиме (`IsXrActive = false`), не пытаясь создать XR Display и не выдавая ошибок в лог.
- **Скачки трекинга (tracking loss):** При кратковременной потере оптического трекинга шлема камера не должна улетать в бесконечность или вызывать дрожание — используется интерполяция и зажим максимальной скорости смещения головы.
- **Смещение origin мира:** Перенос начала координат мира (floating origin T13) не должен смещать опорную точку центрирования внутри автомобиля.
