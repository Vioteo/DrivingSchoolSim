# T38 — Отладочный слой и сценарные тесты района (Traffic Debug Overlay & Scenario Suite)

- **Требования:** R09, R10, R15.
- **Критерий приёмки:** A11, A12.
- **ADR:** ADR-012. Дизайн: [city.md](../city.md#отладка-и-проверка-t38).
- **Зависит от:** T30; расширяется вместе с T31–T36.

## 1. Конкретный результат и зависимости

- `TrafficDebugOverlay` (Presentation, включается клавишей в Play Mode и в сборке разработчика): полосы и связи с цветом по типу разметки, зоны конфликта и владелец резервирования, фазы светофоров, над каждым агентом — решение и причина (`LastReason` из T33/T34), для игрока — `LanePosition` из T31.
- Набор сценариев `DistrictScenarioTests`: граф района v0 + заданные начальные состояния агентов + seed → проверка исхода без графики. Первые сценарии: остановка на красный, помеха справа, поворот налево с пропуском встречных, «не выехал на перекрёсток при заторе», пешеход и TTC 2 с. Сценарии T34 добавляются после 2+2.

## 2. Разрешённая область изменений

- `Assets/DrivingSchool/Code/Presentation/TrafficDebugOverlay.cs`
- `Assets/DrivingSchool/Code/Tests/DistrictScenarioTests.cs`
- Файловый бюджет: 1 production file + 1 test file за итерацию.

## 3. Точные входы, выходы и контракты

- Сценарий — данные (начальные `(laneId, s, v)`, маршруты, план светофора, ожидаемый исход и время); один сценарий — одна проверка.

## 4. Примеры данных и ожидаемого поведения

- «Помеха справа»: исход — первой проезжает машина справа; время до проезда второй ≤ заданного.

## 5. Отрицательные сценарии

- У каждого сценария есть вариант с неверным входом (например, у машины справа знак 2.4), и тест проверяет, что исход меняется. Новый тест сначала падает на неверной реализации.

## 6. Команда проверки и доказательства

```powershell
& $dsUnity -batchmode -nographics -projectPath $dsProject -runTests -testPlatform EditMode -testFilter "DrivingSchool.Tests.DistrictScenarioTests" -testResults "$dsProject/artifacts/reports/district-scenarios.xml" -logFile "$dsProject/artifacts/reports/district-scenarios.log"
```

## 7. Условия завершения

- Слой виден в Play Mode (скриншот C05); сценарии итерации проходят (exit code 0). Карточка повторяемая.
