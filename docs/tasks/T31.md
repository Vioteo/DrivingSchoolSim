# T31 — Привязка участника к графу (Lane Localization)

- **Требования:** R09, R10.
- **Критерий приёмки:** A11, A12.
- **ADR:** ADR-001, ADR-012. Дизайн: [city.md](../city.md#привязка-участника-к-графу).
- **Зависит от:** T27 (граф), для интеграции — T29.

## 1. Конкретный результат и зависимости

Pure C# `LaneLocator` по позе участника (x, z, курс, габарит) возвращает `LanePosition`: `laneId` или `connectionId` (внутри перекрёстка), `s`, `d`, угол к полосе, флаг «вне дороги», список действующих знаков и зон. Пространственный индекс по сетке для быстрого поиска кандидатов.

## 2. Разрешённая область изменений

- `Assets/DrivingSchool/Code/World/LaneLocator.cs` (или pure-модуль, выбранный в T29)
- `Assets/DrivingSchool/Code/Tests/LaneLocatorTests.cs`
- Файловый бюджет: 1–2 production files + 1 test file.

## 3. Точные входы, выходы и контракты

```csharp
public sealed class LaneLocator
{
    public LaneLocator(WorldDocumentV2 graph);
    public LanePosition Locate(string participantId, double x, double z, float headingRad, LanePosition previous);
}
```

- `previous` даёт гистерезис: смена полосы засчитывается, когда центр машины ушёл за границу на 0,3 м (игровой параметр в данных).
- Внутри перекрёстка выбирается связь, согласованная с полосой въезда и курсом, а не ближайшая геометрически.

## 4. Примеры данных и ожидаемого поведения

- Машина на прямой в 0,2 м правее оси своей полосы: `d = +0.2`, `s` растёт с движением.
- Машина качается на границе двух попутных полос с амплитудой 0,1 м → полоса не меняется.
- Поворот налево на кресте: после стоп-линии `connectionId` = связь «налево», после выезда — полоса выезда.

## 5. Отрицательные сценарии

- Машина на тротуаре или газоне → «вне дороги», без исключений.
- Машина задом по встречной полосе → полоса определяется, флаг «против направления».
- Производительность: 100 участников × 1000 вызовов укладываются в заданный в тесте бюджет (зафиксировать число после первого замера).
