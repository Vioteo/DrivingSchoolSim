# T08 — Модель сцепления и проскальзывания (Clutch Dynamics Model)

- **Требования:** R04 (сцепление, передача момента), R15 (доказуемость).
- **Критерий приёмки:** A06 (drivetrain criteria).
- **ADR:** ADR-007 (калибруемая динамика), ADR-005 (семантика педалей).

## 1. Конкретный результат и зависимости

Разработать чистую C# модель дискового сцепления `ClutchModel` в сборке `DS.Simulation`:
- Семантика педали сцепления:
  - `clutch = 1.0` — педаль выжата в пол, диски полностью разомкнуты, передаваемый момент строго 0 Нм.
  - `clutch = 0.0` — педаль полностью отпущена, диски сомкнуты с максимальной прижимной силой (`maxTorqueNm = 240`).
  - Промежуточный диапазон (точка схватывания, обычно 0.4..0.6 хода педали) с прогрессивной характеристикой зацепления.
- Расчет скорости скольжения `slipRpm = engineRpm - gearboxInputRpm`.
- Два режима работы: режим кинетического скольжения (kinetic friction) и режим блокировки (lockup/static friction).
- Вычисление крутящего момента, прикладываемого к двигателю (тормозящий) и к первичному валу КПП (разгоняющий).

## 3. Точные входы, выходы и контракты

- **Контракт интерфейса:**
  ```csharp
  public class ClutchModel
  {
      public float TransmittedTorqueNm { get; }
      public bool IsLockedUp { get; }
      public float SlipSpeedRpm { get; }
      public void Update(float clutchPedal, float engineRpm, float gearboxInputRpm, float maxCapacityNm, float dtSeconds);
  }
  ```
- **Входы:** Положение педали `clutchPedal [0..1]`, угловые скорости маховика и первичного вала, максимальная емкость сцепления `maxCapacityNm` (из `vehicle.json`, по умолчанию 240 Нм).
- **Выходы:** `TransmittedTorqueNm` (знак согласуется с направлением разности скоростей).

## 4. Примеры данных и ожидаемого поведения

- **Выжатое сцепление (`clutchPedal = 1.0f`):** Независимо от того, вращается ли двигатель со скоростью 5000 rpm, а первичный вал стоит (0 rpm), переданный момент равен строго 0.0 Нм.
- **Плавное отпускание на 50% (`clutchPedal = 0.5f`):** Емкость сцепления равна 120 Нм; при наличии проскальзывания передается момент, ускоряющий первичный вал и замедляющий коленвал.
- **Полное зацепление (`clutchPedal = 0.0f`):** При разнице скоростей менее 5 rpm сцепление переходит в режим `IsLockedUp = true`, синхронизируя скорости обоих валов.

## 5. Отрицательные сценарии

- **Отрицательная педаль или значение больше 1.0:** Входной параметр клампится в диапазон `[0..1]`. При передаче NaN/Infinity выбрасывается `ArgumentOutOfRangeException`.
- **Вращение коробки быстрее двигателя (торможение двигателем):** При `gearboxInputRpm > engineRpm` знак передаваемого момента корректно меняется на противоположный (коробка крутит двигатель, двигатель оказывает сопротивление).
- **Отказ от бесконечного момента при нулевом dt:** Защита от деления на ноль при вычислении производных.
