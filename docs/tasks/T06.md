# T06 — Жизненный цикл обратной связи FFB (Force Feedback Lifecycle)

- **Требования:** R03 (FFB), R15 (доказуемость).
- **Критерий приёмки:** A05 (FFB safety & lifecycle).
- **ADR:** ADR-005 (безопасный FFB и ограничение момента).

## 1. Конкретный результат и зависимости

Создать контроллер обратной связи `ForceFeedbackController`, управляющий вызовами интерфейса `IForceFeedbackOutput`:
- Преобразование физического момента выравнивания колес (self-aligning torque, в Нм) в нормализованный момент `[-1.0 .. +1.0]`.
- Защитное ограничение (clamp) и защита от резких скачков (slew rate limiter).
- Гарантированное и идемпотентное обнуление момента (`Stop()`) при событиях:
  - Пауза симуляции (`Pause()`).
  - Потеря фокуса приложения (`OnApplicationFocus(false)`).
  - Отключение устройства / disconnect.
  - Уничтожение объекта (`Dispose()`).
- Разрешение момента только при явном возобновлении симуляции.

## 3. Точные входы, выходы и контракты

- **Интерфейс выхода:** `DrivingSchool.Contracts.IForceFeedbackOutput`:
  ```csharp
  public interface IForceFeedbackOutput : IDisposable
  {
      bool IsAvailable { get; }
      void SetNormalizedTorque(float torque);
      void Stop();
  }
  ```
- **Входы:** Физический момент на рулевом валу `float aligningTorqueNm`, максимальный момент мотора `float maxMotorTorqueNm`, статус симуляции `bool isRunning`.
- **Выходы:** Вызовы `SetNormalizedTorque(clampedValue)` и `Stop()`.

## 4. Примеры данных и ожидаемого поведения

- При `aligningTorqueNm = 4.0` и `maxMotorTorqueNm = 2.5` (удар о бордюр): контроллер отправляет `SetNormalizedTorque(1.0f)` (без превышения 1.0).
- При `aligningTorqueNm = -1.25` и `maxMotorTorqueNm = 2.5`: контроллер отправляет `SetNormalizedTorque(-0.5f)`.
- При вызове `controller.Pause()` немедленно вызывается `output.Stop()`, и последующие тики физики не вызывают `SetNormalizedTorque`, пока не будет вызван `Resume()`.

## 5. Отрицательные сценарии

- **Передача NaN или Infinity:** Если расчет физики дал NaN, контроллер обязан перехватить значение, вызвать `Stop()` и залогировать ошибку, не передавая NaN в драйвер устройства (что в ряде систем вызывает сбой драйвера Logitech).
- **Многократный Stop / Dispose:** Вызов `Stop()` десять раз подряд или повторный `Dispose()` не должен вызывать исключений.
- **Отсутствие доступного FFB устройства (`IsAvailable == false`):** Контроллер переходит в режим graceful bypass, не выбрасывая исключений в основной поток симуляции.
