# T01 — Воспроизводимая подготовка проекта (Prepare Idempotence)

- **Требования:** R01 (платформа), R15 (доказуемость).
- **Критерий приёмки:** A01 (reproducibility).
- **ADR:** ADR-001 (границы сборок), ADR-010 (привязка к хешу).

## 1. Конкретный результат и зависимости

Обеспечить полную идемпотентность метода `DrivingSchool.Editor.ProjectBuilder.Prepare` (команда C02). Повторный вызов Prepare подряд не должен создавать дубликатов ассетов (`* 1.asset`), изменять существующие GUID в `.meta`, перезаписывать пользовательские изменения или оставлять «грязный» diff в репозитории. При отсутствии входных FBX метод должен завершаться с явной ошибкой до модификации сцены.

## 2. Разрешённая область изменений

- `Assets/DrivingSchool/Code/Editor/ProjectBuilder.cs`
- Файловый бюджет: ≤ 2 production files, 0 runtime code.
- Запрещено менять pure-сборки (`DS.Contracts`, `DS.Simulation`, `DS.Learning`).

## 3. Точные входы, выходы и контракты

- **Входы:**
  - Наличие файлов `Assets/DrivingSchool/Art/DS_Sedan_A.fbx`, `DS_District.fbx`, `DS_Autodrome.fbx`.
  - Существующие ассеты URP (`UniversalRenderPipelineAsset`, `UniversalRendererData`).
- **Выходы:**
  - Лог `artifacts/reports/prepare.log` с маркером `DS_PREPARE_PASS`.
  - Сцены `Showroom.unity`, `District.unity`, `Autodrome.unity` в `Assets/DrivingSchool/Scenes/`.
- **Контракты:** Вызов через `-executeMethod DrivingSchool.Editor.ProjectBuilder.Prepare -quit`.

## 4. Примеры данных и ожидаемого поведения

- Первый вызов Prepare на чистом проекте:
  - Создает недостающие папки, сцены и URP ассеты.
  - Назначает fixedDeltaTime = 0.01s (100 Hz), default resolution 1280×720.
  - В лог выводится `DS_PREPARE_PASS`.
- Второй вызов Prepare подряд:
  - Обнаруживает существующие сцены и URP profile через `AssetDatabase.LoadAssetAtPath`.
  - Не вызывает `AssetDatabase.CreateAsset` для уже существующих файлов.
  - Не модифицирует мета-файлы.
  - Завершается с exit code 0 и тем же маркером `DS_PREPARE_PASS`.

## 5. Отрицательные сценарии

- **Отсутствие FBX модели:** Если переименовать или удалить `Assets/DrivingSchool/Art/DS_Sedan_A.fbx`, вызов Prepare обязан прерваться с `FileNotFoundException("Required model DS_Sedan_A.fbx is missing")` до создания/перезаписи сцены Showroom. Не допускается создание сцены с пустым префабом или null mesh.
- **Поврежденный URP asset:** Если ассет пайплайна поврежден, Prepare должен выдать понятное сообщение об ошибке, а не перезаписывать его дефолтным без предупреждения.

## 6. Команда проверки и доказательства

```powershell
# Запуск 1
& $dsUnity -batchmode -projectPath $dsProject -executeMethod DrivingSchool.Editor.ProjectBuilder.Prepare -quit -logFile "$dsProject/artifacts/reports/prepare-run1.log"
# Запуск 2
& $dsUnity -batchmode -projectPath $dsProject -executeMethod DrivingSchool.Editor.ProjectBuilder.Prepare -quit -logFile "$dsProject/artifacts/reports/prepare-run2.log"
# Проверка diff
git status --porcelain
```

Доказательства:
- `artifacts/reports/prepare-run1.log` (exit code 0, маркер `DS_PREPARE_PASS`).
- `artifacts/reports/prepare-run2.log` (exit code 0, маркер `DS_PREPARE_PASS`).
- Отсутствие нежелательных изменений в `git status`.

## 7. Условия завершения

- Двойной запуск C02 отрабатывает с exit code 0.
- В логах отсутствуют `error CS` и непредусмотренные исключения `NullReferenceException`.
- Все три сцены открываются в Unity без missing scripts/materials.
