# T12 — Жизненный цикл чанка мира (Chunk Streaming Lifecycle)

- **Требования:** R06 (территория 10 × 10 км, чанки 256 м), R15 (доказуемость).
- **Критерий приёмки:** A08 (streaming & large world).
- **ADR:** ADR-004 (двойные канонические координаты и чанки 256 м).

## 1. Конкретный результат и зависимости

Разработать сервис потоковой загрузки и жизненного цикла чанков `ChunkStreamingService` в сборке `DS.World`:
- Размер ячейки сетки строго 256 × 256 м.
- Формула индексации ячеек: `cellX = (int)Math.Floor(worldX / 256.0)`, `cellZ = (int)Math.Floor(worldZ / 256.0)`. Корректная работа с отрицательными координатами (диапазон для карты 10 × 10 км: от −20 до +20).
- Фазовый жизненный цикл чанка:
  - `Unloaded` — данные на диске.
  - `Loading` — асинхронная загрузка геометрии/дескриптора.
  - `Active` (ядро коллизий, по умолчанию радиус 3 × 3 ячейки вокруг машины) — активные коллайдеры и физика.
  - `Dormant/VisibleOnly` (периферия, радиус 5 × 5) — только рендеринг дальних LOD без тяжелых коллайдеров.
  - `Unloading` — безопасная выгрузка из памяти с очисткой временных ресурсов.
- Жесткий бюджет одновременного присутствия в памяти (resident chunks budget ≤ 25 чанков).

## 3. Точные входы, выходы и контракты

- **Контракт интерфейса:**
  ```csharp
  public enum ChunkState { Unloaded, Loading, Active, VisibleOnly, Unloading }

  public class ChunkStreamingService
  {
      public int ActiveChunkCount { get; }
      public ChunkState GetState(int cx, int cz);
      public void UpdateFocusPosition(double playerWorldX, double playerWorldZ, double headingYawDeg, double speedMps);
      public IEnumerable<ChunkCoordinate> GetChunksToLoad();
      public IEnumerable<ChunkCoordinate> GetChunksToUnload();
  }
  ```
- **Входы:** Каноническая позиция автомобиля `double x, z`, курс и скорость (для предиктивной загрузки по вектору движения).
- **Выходы:** События загрузки/активации/выгрузки ячеек.

## 4. Примеры данных и ожидаемого поведения

- Автомобиль находится в точке `(x = 100.0, z = -10.0)`:
  - Текущая ячейка: `cellX = floor(100/256) = 0`, `cellZ = floor(-10/256) = -1`.
  - В радиусе 1 (3 × 3) активируются ячейки с X от −1 до 1, Z от −2 до 0.
- Автомобиль перемещается в точку `(x = 300.0, z = -10.0)` (`cellX = 1`):
  - Ячейки столбца `cellX = -1` покидают активную зону и переходят в `VisibleOnly` или `Unloading`.
  - Ячейки столбца `cellX = 2` загружаются и активируются.
  - Число активных ячеек стабильно равно 9, общее число загруженных не превышает 25.

## 5. Отрицательные сценарии

- **Движение сквозь границу чанка на высокой скорости:** Алгоритм не должен задерживать активацию коллизий — коллизии должны быть готовы до физического пересечения границы автомобиля. При дефиците загрузки выставляется флаг `StreamBarrierPending`, блокирующий движение вперед до готовности асфальта.
- **Отрицательные координаты возле нуля:** Точка `(-0.1, -0.1)` обязана давать индекс `(-1, -1)`, а не `(0, 0)` из-за неверного усечения к нулю при касте к int (использовать `Math.Floor`).
- **Синтетический стресс-тест 10 × 10 км:** Прогон виртуального движения на 10 км в обоих направлениях не вызывает утечек памяти (GC allocation стремится к 0 B в стационарном режиме).
