# T30 — Генератор тестового района (District Scene Builder)

- **Требования:** R06, R07, R09.
- **Критерий приёмки:** A07, A09 (часть сборки сцены из графа).
- **ADR:** ADR-003, ADR-011. Дизайн: [city.md](../city.md#тестовый-район).
- **Зависит от:** T29; для состава v0 — T39 (короткие прямые, Т-перекрёсток).

## 1. Конкретный результат и зависимости

- Раскладка `Assets/DrivingSchool/Data/City/test-district-v0.layout.json` по составу v0 из city.md.
- Editor-генератор `DistrictBuilder` (меню **Driving School → City → Build test district**, batch `-executeMethod DrivingSchool.Editor.DistrictBuilder.Build`):
  компилирует раскладку → пишет `Assets/DrivingSchool/Data/City/test-district-v0.world.json` → создаёт сцену `Assets/DrivingSchool/Scenes/City_TestDistrict.unity`: префабы модулей, знаки и светофоры **из графа**, дома по краям кварталов, коллайдеры.
- Отчёт `artifacts/reports/district-build.json`: число модулей, полос, связей, знаков; SHA256 раскладки и выходного графа; расхождения шаблон ↔ меш.
- Генератор перезаписывает только свои файлы; другие сцены и список сцен сборки не трогает. Сгенерированное руками не правится (CLAUDE.md, правило 2).

## 2. Разрешённая область изменений

- `Assets/DrivingSchool/Code/Editor/DistrictBuilder.cs`
- `Assets/DrivingSchool/Data/City/test-district-v0.layout.json`
- `Assets/DrivingSchool/Code/Tests/DistrictBuildTests.cs` (проверки сгенерированной сцены)
- Файловый бюджет: 1 production file + данные + 1 test file.

## 3. Точные входы, выходы и контракты

- Корни префабов — identity + дочерний `Model` (art-pipeline.md). Объекты в сцене именуются по `id` из графа.
- Положение знаков и светофоров — только из `SignPlacement` и привязок светофоров графа.

## 4. Примеры данных и ожидаемого поведения

- После сборки в сцене столько же знаков, сколько `SignPlacement` в графе; у каждого светофора компонент ссылается на свою группу сигналов по `id`.
- Повторная сборка без изменений раскладки даёт тот же SHA256 графа.

## 5. Отрицательные сценарии

- Ошибка компилятора → сцена и JSON не перезаписываются, в логе причина.
- Стоп-линия шаблона не совпадает с разметкой меша более чем на 5 см → сборка падает с отчётом.

## 6. Команда проверки и доказательства

```powershell
& $dsUnity -batchmode -nographics -projectPath $dsProject -executeMethod DrivingSchool.Editor.DistrictBuilder.Build -quit -logFile "$dsProject/artifacts/reports/district-build.log"
& $dsUnity -batchmode -nographics -projectPath $dsProject -runTests -testPlatform EditMode -testFilter "DrivingSchool.Tests.DistrictBuildTests" -testResults "$dsProject/artifacts/reports/district-build-tests.xml" -logFile "$dsProject/artifacts/reports/district-build-tests.log"
```

Дополнительно C05: скриншот сцены сверху и из салона, с указанием ревизии.

## 7. Условия завершения

- Сцена собирается batch-командой без ручных шагов, повторная сборка идемпотентна.
- Тесты сцены проходят; скриншоты приложены.
