# T23 — Три зеркала заднего вида для Desktop (Desktop Mirrors System)

- **Требования:** R05 (автомобиль, три зеркала), R15 (доказуемость).
- **Критерий приёмки:** A13 (mirrors criteria).
- **ADR:** ADR-009 (desktop и XR зеркала), ADR-010 (ассет и привязка к хешу).

## 1. Конкретный результат и зависимости

Разработать компонент управления зеркалами заднего вида `VehicleMirrorRig` в сборке `DS.Presentation`:
- Интеграция с тремя сокетами модели седана: `MirrorSurface_L`, `MirrorSurface_R`, `MirrorSurface_Centre`.
- Расчет косой проекции (oblique near-plane clipping) под плоскость каждого зеркала относительно точки взгляда водителя `Socket_DriverEye`.
- Создание RenderTexture для каждого зеркала (разрешение по умолчанию 512 × 256, формат R8G8B8A8_UNorm).
- Оптимизация частоты обновления (time-slicing / staggered refresh):
  - Центральное зеркало: каждый кадр.
  - Боковые зеркала: поочередно через кадр (каждое обновляется на половинной частоте), что экономит 33% отрисовок.
- Исключение утечек памяти: гарантированный вызов `Release()` и уничтожение `RenderTexture` при деактивации компонента (`OnDisable`, `OnDestroy`).
- Корректная ориентация отражения (левое/правое не перепутаны, нормали отражения согласованы).

## 3. Точные входы, выходы и контракты

- **Контракт интерфейса:**
  ```csharp
  public class VehicleMirrorRig : MonoBehaviour
  {
      public bool EnableTimeSlicing = true;
      public Vector2Int TextureResolution = new Vector2Int(512, 256);
      public void SetActiveMirrors(bool left, bool center, bool right);
      public RenderTexture GetMirrorTexture(MirrorSlot slot);
  }
  ```
- **Входы:** Трансформы поверхностей зеркал в иерархии `DS_Sedan_A`, положение камеры водителя.
- **Выходы:** Назначение свойств `_MirrorTex_L`, `_MirrorTex_R`, `_MirrorTex_C` в соответствующие инстансы материалов.

## 4. Примеры данных и ожидаемого поведения

- Водитель смотрит прямо:
  - В левом зеркале видна левая полоса позади автомобиля и левое заднее крыло.
  - В правом зеркале видна правая полоса и правое заднее крыло.
  - В центральном салонном зеркале видно заднее стекло и дорога прямо позади автомобиля.
- Динамический маркер, приближающийся сзади-слева, отображается в левом зеркале и перемещается слева направо по мере опережения.

## 5. Отрицательные сценарии

- **Рекурсивный рендеринг (зеркало в зеркале):** Слои отражения зеркал должны исключаться из маски видимости (`cullingMask`) камер зеркал, исключая бесконечную рекурсию рендеринга.
- **Утечка VRAM при рестарте сцены:** Создание и уничтожение компонента 10 раз подряд не должно увеличивать потребление видеопамяти (проверка освобождения RenderTexture).
- **Смещение головы водителя:** При повороте головы угол косой проекции зеркала пересчитывается, отражение не «залипает» в одной позе.
