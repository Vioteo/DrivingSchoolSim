# T32 — Контроллер светофоров с фазами (Signal Controller)

- **Требования:** R09, R10.
- **Критерий приёмки:** A11, A12.
- **ADR:** ADR-001, ADR-003.
- **Зависит от:** T11 (привязка светофоров), T27.

## 1. Конкретный результат и зависимости

- Pure C# `SignalController`: план фаз как данные (группы сигналов, длительности, промежуточные такты, мигающий зелёный, жёлтый мигающий в режиме «отключён»), время — только тик симуляции.
- Для каждой связи полос и каждого перехода выдаёт текущий сигнал: `Red`, `RedAmber`, `Amber`, `Green`, `GreenFlashing`, `AmberFlashing`, `Off`, плюс состояние дополнительной секции.
- `TrafficSignalView` получает состояния `GreenFlashing` и `AmberFlashing`. `CrossroadSignalCycle` остаётся на автодроме, в городе не используется.

Значение сигналов для правил — ПДД РФ, п. 6.2 и 6.3 (редакцию сверить и записать в данные плана).

## 3. Точные входы, выходы и контракты

```csharp
public sealed class SignalController
{
    public SignalController(SignalPlan plan);
    public void Tick(double simSeconds);
    public SignalAspect GetAspect(string signalGroupId);
    public double TimeToChange(string signalGroupId);
}
```

## 4. Примеры данных и ожидаемого поведения

- План из двух фаз 18/3/2 с: две группы никогда одновременно не зелёные; мигающий зелёный — последние 3 с зелёного (игровой параметр в данных).
- Пешеходная группа зелёная только в такте, когда пересекаемые связи красные.

## 5. Отрицательные сценарии

- План, в котором конфликтующие группы (по зонам конфликта графа) зелёные одновременно, → ошибка валидации плана.
- Пауза симуляции не двигает фазы; FPS 30/60/120 не меняет время фаз.
