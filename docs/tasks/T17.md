# T17 — Пешеходный переход и агент пешехода (Pedestrian Crossing Agent)

- **Требования:** R09 (пешеходы пересекают дорогу по связи с графом), R15 (доказуемость).
- **Критерий приёмки:** A11 (agents & pedestrian crossing).
- **ADR:** ADR-003 (roadgraph как единый источник), ADR-001 (pure core).

## 1. Конкретный результат и зависимости

Разработать логику пешеходного перехода `PedestrianCrossingZone` и модель движения пешехода `PedestrianAgent` в сборке `DS.Simulation`:
- Привязка пешеходного перехода к дорожному графу: переход знает пересекаемые полосы `Lane` и их границы.
- Фазовый автомат пешехода:
  - `WaitingAtCurb` — пешеход стоит на тротуаре у края проезжей части.
  - `EvaluatingGap` — оценка времени до приближающегося ТС (Time to Collision, TTC > 4.5 с) или проверка разрешающего пешеходного светофора.
  - `Crossing` — движение поперек проезжей части со скоростью шага 1.3 ± 0.2 м/с.
  - `ReachedOppositeCurb` — завершение перехода, сход с проезжей части.
- Публикация занятости зоны перехода для автомобиля игрока, трафика (`LaneFollowerAgent`) и правил ПДД (уступи дорогу пешеходу).

## 3. Точные входы, выходы и контракты

- **Контракт интерфейса:**
  ```csharp
  public enum PedestrianPhase { WaitingAtCurb, Crossing, ReachedOppositeCurb }

  public class PedestrianAgent
  {
      public PedestrianPhase Phase { get; }
      public double WorldX { get; }
      public double WorldZ { get; }
      public bool IsOnRoadway { get; }
      public void Update(float dtSeconds, float nearestApproachingVehicleTtc, bool isWalkSignalGreen);
  }
  ```
- **Входы:** Шаг времени `dt`, расстояние/TTC до приближающихся машин, сигнал светофора.
- **Выходы:** Позиция пешехода `(WorldX, WorldZ)`, флаг присутствия на проезжей части `IsOnRoadway`.

## 4. Примеры данных и ожидаемого поведения

- **Нерегулируемый переход, машина приближается (TTC = 2.0 с):**
  - Пешеход находится в фазе `WaitingAtCurb` и не выходит на проезжую часть прямо перед автомобилем.
- **Машина снижает скорость и останавливается:**
  - Пешеход начинает переход (`Crossing`), выходит на полосу, флаг `IsOnRoadway` становится `true`.
  - После пересечения полосы и выхода на тротуар `IsOnRoadway` переходит в `false`.

## 5. Отрицательные сценарии

- **Выбегание под колеса:** Пешеход не должен телепортироваться на середину полосы прямо перед автомобилем без перехода через фазу ожидания на обочине.
- **Красный сигнал пешеходного светофора:** На регулируемом переходе пешеход обязан стоять на тротуаре, даже если на дороге нет машин, до включения зеленого сигнала.
- **Зависание на середине перехода:** Движение пешехода через проезжую часть непрерывно; при остановке машин пешеход продолжает движение до безопасной зоны противоположного тротуара.
