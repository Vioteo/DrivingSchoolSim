# T15 — Надежное сохранение и восстановление данных (Persistence Resilience & Recovery)

- **Требования:** R08 (сохранения вне AssetDatabase в `persistentDataPath`), R15 (доказуемость).
- **Критерий приёмки:** A10 (persistence resilience).
- **ADR:** ADR-002 (версионирование данных), ADR-004 (отказ от AssetDatabase в рантайме).

## 1. Конкретный результат и зависимости

Укрепить класс `WorldRepository` в сборке `DS.World` для промышленной надежности в Windows Standalone:
- **Атомарная запись (Safe Atomic Save):**
  1. Сериализация в строго временный файл `name.json.tmp`.
  2. Валидация записанного JSON перед фиксацией.
  3. Атомарная замена файла через `File.Replace` с сохранением предыдущей рабочей версии в `name.json.bak`.
- **Автоматическое восстановление при сбоях (Crash Recovery):**
  - При обнаружении поврежденного файла (нулевой размер, оборванный JSON, мусор вместо UTF-8) метод `Load()` автоматически пытается восстановить данные из `name.json.bak` с фиксацией предупреждения в лог.
- **Безопасность путей (Path Traversal Protection):**
  - Жесткий запрет имен, содержащих `..`, слэши `/` и `\`, двоеточия и недопустимые символы ОС.
- **Лимиты размера и контроль свободного места:**
  - Проверка размера перед вычиткой (лимит документа карты 50 МБ).

## 3. Точные входы, выходы и контракты

- **Контракт интерфейса:**
  ```csharp
  public class WorldRepository
  {
      public void Save(string name, WorldDocument doc);
      public WorldDocument Load(string name);
      public bool Exists(string name);
      public bool TryRecoverFromBackup(string name, out WorldDocument recoveredDoc);
  }
  ```
- **Входы:** Имя карты (например, `"user_custom_map"`), экземпляр `WorldDocument`.
- **Выходы:** Файлы `user_custom_map.json` и `user_custom_map.json.bak` в папке сохранений.

## 4. Примеры данных и ожидаемого поведения

- Успешное сохранение:
  - Создается `map.json.tmp` → валидируется → замещает `map.json` → старый `map.json` становится `map.json.bak`.
  - Временный файл `.tmp` гарантированно удаляется после операции.
- Сбой во время записи (эмуляция прерывания):
  - При повреждении основного `map.json` вызов `Load("map")` обнаруживает невалидный JSON, читает `map.json.bak`, восстанавливает рабочий документ и возвращает его вызывающей стороне.

## 5. Отрицательные сценарии

- **Path traversal атака:** Вызов `repo.Load("../../../Windows/System32/config")` выбрасывает `ArgumentException("Invalid map name")`.
- **Нулевой размер файла (0 bytes crash):** Попытка чтения пустого файла переключается на `.bak`. Если и бэкап отсутствует, выбрасывается понятное `InvalidDataException` с описанием причины, а не скрытый краш `NullReferenceException`.
- **Неизвестная версия схемы:** Если в JSON указана будущая версия (`schemaVersion = 999`), файл не перезаписывается молча и не обрезается — выбрасывается исключение несовместимости версий.
