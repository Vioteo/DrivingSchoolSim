# T21 — Эвалюатор упражнения «Параллельная парковка» (Autodrome Exercise Evaluator)

- **Требования:** R12 (восемь учебных упражнений автодрома), R15 (доказуемость).
- **Критерий приёмки:** A16 (lessons & exercise evaluation).
- **ADR:** ADR-001 (pure core), ADR-008 (параметрические упражнения).

## 1. Конкретный результат и зависимости

Разработать эвалюатор упражнения автодрома `ParallelParkingEvaluator` в сборке `DS.Learning`:
- Параметры габаритного кармана привязаны к габаритам учебного седана (длина 4.5 м, ширина 1.8 м):
  - Длина парковочного кармана: 7.0 м ($1.5 \times$ длина кузова).
  - Ширина кармана: 2.5 м.
- Пошаговая оценка маневра:
  1. Остановка рядом с передним ориентиром, включение правого указателя поворота (`rightIndicator = true`).
  2. Включение передачи заднего хода (`gear = -1`).
  3. Заезд задним ходом без наезда на контрольные линии/конусы (отслеживание 4 углов габарита кузова).
  4. Положение после парковки:
     - Все 4 колеса и корпус находятся строго внутри габаритного прямоугольника.
     - Угол перекоса относительно бордюра не превышает $\pm 5^\circ$.
     - Зазор до бордюра от 0.15 до 0.40 м.
  5. Фиксация: перевод КПП в нейтраль (`gear = 0`) и включение стояночного тормоза (`handbrake = true`) на время не менее 2.0 секунд.
- Ограничение: не более 2 включений задней передачи за упражнение.

## 3. Точные входы, выходы и контракты

- **Контракт интерфейса:**
  ```csharp
  public interface ILessonEvaluator
  {
      string ExerciseId { get; }
      string EvaluatorVersion { get; }
      void EvaluateStep(double simSeconds, VehicleState state, VehiclePose pose, IList<RuleEvent> outEvents);
      bool IsComplete { get; }
      bool IsSuccessful { get; }
      string CompletionReason { get; }
  }
  ```
- **Входы:** Позиция кузова `(x, y, z, yawDeg)`, состояние автомобиля `VehicleState`.
- **Выходы:** Статусы `IsComplete`, `IsSuccessful`, штрафные события при наезде на разметку.

## 4. Примеры данных и ожидаемого поведения

- Корректная парковка:
  - Автомобиль въехал в карман, выровнялся с углом $+2.1^\circ$, поставил нейтраль и ручник.
  - По истечении 2 с: `IsComplete = true`, `IsSuccessful = true`, `CompletionReason = "Упражнение успешно выполнено"`.
- Наезд на конус:
  - Правое заднее колесо вышло за заднюю границу кармана на 0.05 м.
  - Генерируется событие `RuleEvent` с `ruleId = "PARKING_BOUNDARY_VIOLATION"`, упражнение переходит в статус ошибки.

## 5. Отрицательные сценарии

- **Выравнивание без ручника:** Если водитель заехал идеально, но не поставил на ручник, упражнение не засчитывается как успешное.
- **Превышение числа переключений R:** Третье включение заднего хода приводит к фиксации ошибки («Превышено число попыток маневра»).
- **Слишком сильный перекос:** Автомобиль запаркован под углом $18^\circ$ (косо) — отказ в зачете упражнения с указанием причины «Автомобиль не параллелен краю проезжей части».
