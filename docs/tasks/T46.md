# T46 — Запуск через главное меню, пауза и живой фон меню

- **Требования:** R01 (UI). **Приёмка:** A03. **Связано:** T03 (главное меню), `docs/ui-settings.md` §1 (карта экранов), T41 (тестовый полигон).

## Результат

- Сцена `Scenes/MainMenu.unity` — первая в Build Settings. Её собирает генератор **Driving School → Build Main Menu scene** (`UIBuilder.BuildMenuScene`, входит и в *Build UI Prefabs*). Руками не править.
- **Play в редакторе стартует с главного меню**, из какой бы сцены его ни нажали (`EditorSceneManager.playModeStartScene`). Выключается пунктом **Driving School → Play from Main Menu** (галочка, хранится в EditorPrefs этого компьютера). В batchmode не действует.
- Главное меню (T03): «Продолжить занятие» и «Занятия» запускают тестовый полигон `VehicleTestRange`; «Теория ПДД» показывает «в разработке», «Настройки» открывают экран настроек (T43); «Выход» — через диалог подтверждения.
- **Пауза в поездке**: Esc / Start геймпада. «Продолжить», «Начать заново», «Выйти в главное меню». На паузе `Time.timeScale = 0`, звук на паузе, скрипты `DrivingSchool.*` сцены (кроме UI) выключены — клавиши поездки за меню не срабатывают. Префаб `Prefabs/UI/PauseMenu.prefab` (генератор `UIBuilder.BuildPauseMenu`). Пауза добавляется в сцену поездки, только если её загрузило меню.
- **Живой фон меню** (`Presentation/MenuBackdropDirector.cs`): при каждом входе в меню случайно (без повтора подряд) выбирается сцена — шоурум с седаном (`Showroom`), ж/д переезд с поездом раз в ~40 с (`VehicleTestRange`), автодром (`Autodrome_Training`). Сцена грузится аддитивно, до первого `Start` у неё выключаются машина игрока, директоры, их камеры и горячие клавиши; снимает камера меню медленным облётом. Сцены-источники не копируются и не меняются — фон всегда актуален. Список фонов и ракурсы — `UIBuilder.MenuBackdrops()`.
- Слева под пунктами меню — градиент затемнения (`Art/UI/MenuScrim.png`, создаёт генератор).

`Presentation/UI/AppNavigator.cs` (переходы сцен), `MainMenuFlow.cs` (связка меню со сценами), `PauseMenuController.cs`; `Presentation/MenuBackdropDirector.cs`; `Editor/PlayFromMainMenu.cs`; `Editor/UIBuilder.cs`. `DS.Tests` теперь ссылается на `DS.Presentation` (и в `tools/setup_project.py`).

## Проверка

- EditMode `DrivingSchool.Tests.UITests` — 15/15 PASS (27.09.2026, Unity 6000.3.10f1, через Unity MCP): пауза замораживает время и скрипты поездки и возвращает прежний `timeScale`; «Продолжить» без паузы ничего не меняет; выход в меню размораживает время; меню — первая сцена сборки; все сцены фона в сборке; выбор фона не повторяет предыдущий.
- Play Mode вручную через MCP: меню → полигон → пауза → меню; каждый из трёх фонов; поезд проходит переезд в кадре. Скриншоты: `artifacts/reports/t46-*.png`.

## Ограничения

- Каталог занятий, теория, калибровка — пока макеты-префабы без логики (`LessonCatalog`, `ConditionsSetup`, `G27Calibration`, `TheoryExam`), в поток не подключены.
- `ProjectBuilder.Prepare` перезаписывает список сцен сборки (Showroom/District/Autodrome) — после него перезапустить *Build Main Menu scene*.
- Вход в фоновую сцену тратит время загрузки полигона/автодрома (секунды); пока фон грузится, под меню тёмная заливка.
