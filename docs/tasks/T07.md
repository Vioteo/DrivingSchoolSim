# T07 — Числовая валидация и модель двигателя (Engine Simulation Model)

- **Требования:** R04 (учебная динамика двигателя), R15 (доказуемость).
- **Критерий приёмки:** A06 (drivetrain criteria).
- **ADR:** ADR-007 (калибруемая динамика), ADR-001 (pure core).

## 1. Конкретный результат и зависимости

Разработать детерминированную модель двигателя внутреннего сгорания `EngineModel` в сборке `DS.Simulation`:
- Фазовый автомат двигателя: `EnginePhase.Off` → `Ignition` → `Cranking` → `Running` → `Stalled`.
- Обороты двигателя: холостой ход `idleRpm = 850`, отсечка `redlineRpm = 6500`, критические обороты заглохания `stallRpm = 400`, инерция маховика `inertiaKgm2 = 0.2`.
- Расчет крутящего момента двигателя `EngineTorque(rpm, throttle)` по кривой крутящего момента.
- Логика заглохания: если при отпущенном сцеплении обороты падают ниже `stallRpm` из-за нагрузки колес, фаза переходит в `Stalled`, а двигатель прекращает генерировать крутящийся момент.
- Укрепление `DrivetrainMath`: строгая проверка входных параметров на `float.IsNaN` и `float.IsInfinity`.

## 3. Точные входы, выходы и контракты

- **Контракт интерфейса:**
  ```csharp
  public class EngineModel
  {
      public EnginePhase Phase { get; }
      public float Rpm { get; }
      public float OutputTorqueNm { get; }
      public void Update(float throttle, bool ignition, bool starter, float loadTorqueNm, float dtSeconds);
      public void Reset();
  }
  ```
- **Входы:** Степень нажатия газа `throttle [0..1]`, флаги зажигания/стартера, момент нагрузки от сцепления `loadTorqueNm`, шаг времени `dtSeconds`.
- **Выходы:** Текущие `EnginePhase`, `Rpm`, `OutputTorqueNm`.

## 4. Примеры данных и ожидаемого поведения

- **Запуск двигателя:**
  1. `ignition = true` → фаза `Ignition`, обороты 0.
  2. `starter = true` на 0.8 с → фаза `Cranking`, обороты раскручиваются стартером до 450 rpm.
  3. Обороты превысили порог запуска → переход в `Running`, обороты стабилизируются регулятором холостого хода на 850 ± 15 rpm.
- **Работа педалью газа на нейтрали (`loadTorqueNm = 0`):**
  - При `throttle = 1.0` обороты растут со скоростью, определяемой моментом и инерцией `dOmega = (T_eng - T_fric) / I * dt`.
  - При достижении 6500 rpm срабатывает отсечка топлива, обороты не превышают 6600 rpm.

## 5. Отрицательные сценарии

- **Заглохание под нагрузкой:** При `loadTorqueNm = 300 Нм` и `throttle = 0.0` обороты падают ниже 400 rpm → фаза переключается в `Stalled`. После заглохания двигатель не заводится без повторного включения стартера.
- **Включение стартера при работающем двигателе:** Если двигатель уже в фазе `Running`, подача сигнала `starter = true` не должна ломать симуляцию или сбрасывать обороты.
- **Подача невалидного dt:** При `dt <= 0`, `float.NaN` или отрицательном throttle выбрасывается `ArgumentOutOfRangeException`.
