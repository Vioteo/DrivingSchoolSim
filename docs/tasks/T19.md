# T19 — Сцепление покрытия и влияние погоды (Surface Friction & Weather)

- **Требования:** R11 (погода и сцепление: сухой, мокрый, снег, лед), R15 (доказуемость).
- **Критерий приёмки:** A15 (weather & surface friction criteria).
- **ADR:** ADR-007 (калибруемая динамика), ADR-001 (pure core).

## 1. Конкретный результат и зависимости

Разработать модель характеристик дорожного покрытия и влияния погодных условий `SurfaceFrictionModel` в сборке `DS.Simulation`:
- Базовые типы покрытий и коэффициенты трения скольжения $\mu$:
  - `DryAsphalt`: $\mu \approx 0.95$ (сухой асфальт).
  - `WetAsphalt`: $\mu \approx 0.65$ (мокрый асфальт во время дождя).
  - `PackedSnow`: $\mu \approx 0.30$ (укатанный снег, зимняя дорога).
  - `BlackIce`: $\mu \approx 0.15$ (гололедица).
- Плавный переход коэффициента сцепления между соседними поверхностями без разрыва первой производной (исключение бесконечных ускорений).
- Влияние на продольную и поперечную силу колес: предельная сила сцепления $F_{max} = \mu \cdot F_z$.
- Тормозной след: контролируемое увеличение тормозного пути в зависимости от покрытия при одинаковых начальных условиях (скорость 60 км/ч, полное нажатие тормоза).

## 3. Точные входы, выходы и контракты

- **Контракт интерфейса:**
  ```csharp
  public enum SurfaceType { DryAsphalt, WetAsphalt, PackedSnow, BlackIce }

  public static class SurfaceFrictionModel
  {
      public static float GetFrictionCoefficient(SurfaceType surface);
      public static float CalculateMaxTireForce(float normalForceN, SurfaceType surface);
      public static float CalculateStoppingDistanceM(float initialSpeedMps, SurfaceType surface);
  }
  ```
- **Входы:** Тип покрытия `surface`, нормальная нагрузка на колесо $F_z$ (в Ньютонах).
- **Выходы:** Коэффициент трения $\mu$, предельная сила сцепления $F_{max}$ (Н).

## 4. Примеры данных и ожидаемого поведения

- Нормальная нагрузка на колесо $F_z = 3300$ Н (четверть массы автомобиля 1350 кг):
  - Сухой асфальт ($\mu = 0.95$): $F_{max} = 3135$ Н.
  - Мокрый асфальт ($\mu = 0.65$): $F_{max} = 2145$ Н.
  - Снег ($\mu = 0.30$): $F_{max} = 990$ Н.
  - Лед ($\mu = 0.15$): $F_{max} = 495$ Н.
- Торможение с 60 км/ч (16.67 м/с) до полной остановки:
  - Тормозной путь на льду минимум в 5 раз длиннее тормозного пути на сухом асфальте.

## 5. Отрицательные сценарии

- **Отрицательная нормальная нагрузка (отрыв колеса от земли):** При $F_z \le 0$ возвращается сила сцепления ровно $0.0$ Н (колесо в воздухе не развивает тяги). Исключено деление на ноль или отрицательная сила трения, ускоряющая машину назад.
- **Резкая смена покрытия:** При наезде на ледяное пятно изменение силы клампится по максимальной производной $dF/dt$, исключая численный разрыв в интеграторе физики.
- **Невалидные типы покрытия:** Приведение неизвестного int к `SurfaceType` безопасно фоллбэчится на `DryAsphalt` с предупреждением.
