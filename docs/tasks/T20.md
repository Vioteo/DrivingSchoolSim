# T20 — Жизненный цикл учебной сессии и результат (Lesson Session Lifecycle & Result)

- **Требования:** R12 (учебные занятия), R15 (доказуемость).
- **Критерий приёмки:** A16 (lesson session criteria).
- **ADR:** ADR-001 (pure core), ADR-008 (происхождение контента).

## 1. Конкретный результат и зависимости

Укрепить класс учебной сессии `LessonSession` в сборке `DS.Learning`:
- Полный жизненный цикл фаз:
  - `Briefing` — ознакомление с заданием, инструктаж.
  - `Ready` — автомобиль на стартовой позиции, двигатель запущен.
  - `Running` — выполнение упражнения.
  - `Passed` — успешное выполнение всех критериев.
  - `Failed` — истечение лимита времени, грубое нарушение или сход с траектории.
  - `Cancelled` — прерывание пользователем или перезапуск.
- Формирование полного итогового отчета `SessionResult`:
  - `lessonId`, текстовая причина завершения `reason`.
  - Затраченное время `elapsedSeconds`.
  - Список активных ассистов `enabledAssists` (например, ABS, ESP, авто-сцепление).
  - Список зафиксированных нарушений `RuleEvent[]`.
  - Расчет итогового балла от 0 до 100 с вычетом штрафов.
- Числовая валидация параметров `LessonDefinition` в конструкторе (отсечение NaN/Infinity, нулевых и отрицательных лимитов).

## 3. Точные входы, выходы и контракты

- **Контракт интерфейса:**
  ```csharp
  public class LessonSession
  {
      public SessionPhase Phase { get; }
      public SessionResult Result { get; }
      public void Ready();
      public void Start();
      public void Cancel();
      public void RecordViolation(RuleEvent violation);
      public void Tick(float dtSeconds, float forwardDisplacementM, float currentSpeedMps);
  }
  ```
- **Выходной контракт:** `DrivingSchool.Contracts.SessionResult`.

## 4. Примеры данных и ожидаемого поведения

- Упражнение «Старт и остановка» (дистанция 20 м, время 60 с, остановка на 2 с):
  1. `Ready()` → `Start()`.
  2. Машина проезжает 22 м (`forwardDisplacementM = 22.0`), скорость снижается до 0.05 м/с (< 0.14 м/с).
  3. Остановка удерживается 2.1 секунды.
  4. Фаза переходит в `SessionPhase.Passed`.
  5. `Result.finalScore = 100`, `Result.reason = "Target reached and safely stopped"`.
  6. Последующие тики не меняют результат и не переводят сессию в Failed.

## 5. Отрицательные сценарии

- **Неподвижность на точке спавна:** Если машина простояла 3 секунды без движения (`forwardDisplacementM = 0`), сессия остается в фазе `Running` и не завершается успехом.
- **Превышение лимита времени (Timeout):** При превышении `timeLimitSeconds` сессия немедленно завершается с `SessionPhase.Failed` и причиной `"Time limit exceeded"`.
- **Невалидное определение занятия:** Попытка создать `LessonSession` с `timeLimitSeconds = -10` или `targetDistanceM = float.NaN` выбрасывает `ArgumentOutOfRangeException`.
- **Вызов Start до Ready:** Вызов `Start()` в фазе `Briefing` выбрасывает `InvalidOperationException`.
