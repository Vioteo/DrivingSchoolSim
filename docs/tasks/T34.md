# T34 — Перестроение, объезд и движение в заторе (Lane Change, Bypass & Congestion)

- **Требования:** R09.
- **Критерий приёмки:** A11.
- **ADR:** ADR-012. Дизайн: [city.md](../city.md#перестроение-t34), [объезд](../city.md#объезд-препятствия-t34).
- **Зависит от:** T16 (IDM и следование полосе с поперечным смещением `d`), T27 (разметка), T31, T35 (модуль подключается к диспетчеру), T40 (перестроение, слияние и объезд — запросы `LaneChange`, `MandatoryLaneChange`, `Merge`, `OncomingBypass` с уведомлениями соседям).

## 1. Конкретный результат и зависимости

Pure C# поведенческий слой агента поверх `LaneFollowerAgent`:
- **Перестроение:** траектория `d(t)` — полином 5-й степени, длительность 2–4 с по скорости; на время манёвра агент занимает обе полосы; смена `laneId` на середине. Решение — MOBIL (выгода, вежливость, безопасное торможение нового заднего соседа).
- **Обязательное перестроение под маршрут:** срочность растёт к точке, где надо быть в полосе; не удалось — остановка с поворотником и ожидание окна, затем смена маршрута.
- **Сужение:** поочерёдное слияние.
- **Объезд:** смещение внутри полосы при частичном препятствии → перестроение в попутную → выезд на встречную только при прерывистой разметке и свободной встречной с запасом по TTC → ожидание. Отказ от манёвра на середине не допускается. Правомерность выезда на встречную для объезда препятствия — ссылка на пункты ПДД с редакцией, сверенная исполнителем.
- **Затор:** задержка реакции при трогании по профилю водителя, минимальный зазор `s0`, ползучее движение без рывков.
- Поворотник за 2–3 с до манёвра, стоп-сигнал по замедлению — выходы агента для представления.
- Через сплошную (`LaneBoundary` из графа) агент не перестраивается никогда.

## 2. Разрешённая область изменений

- Файловый бюджет: 2 production files + 1 test file. Все пороги — игровые параметры в данных профиля водителя.

## 3. Точные входы, выходы и контракты

- Вход: `AgentView` себя и соседей в координатах `(laneId, s, d, v, a)`, граф, маршрут.
- Выход: целевые `a` и `d`, флаги поворотников, занятые полосы.

## 4. Примеры данных и ожидаемого поведения

- 2+2, впереди медленная машина 30 км/ч, слева свободно: перестроение за 3 с, `|d|` монотонно, боковое ускорение ≤ 2 м/с².
- 1+1, стоящая машина с аварийкой, прерывистая ось, встречная пуста: объезд через встречную и возврат.
- То же, но ось сплошная: агент ждёт, а по истечении времени ожидания меняет маршрут.
- Колонна из 5 машин трогается на зелёный: интервалы старта 0,3–1 с, без столкновений.

## 5. Отрицательные сценарии

- Перестроение в окно, где новому заднему соседу пришлось бы тормозить сильнее порога, → не начинается.
- Встречная машина появляется во время объезда → манёвр завершается с торможением, столкновения нет (сценарий строится так, чтобы решение было корректным на момент начала).
- 1000 случайных seed на прямой 2+2 с 10 агентами → ни одного пересечения габаритов.
