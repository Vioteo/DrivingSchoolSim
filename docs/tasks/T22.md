# T22 — Валидация теории и подтверждение происхождения (Theory Pack & Provenance)

- **Требования:** R13 (теория, источник контента, разделение официального и авторского), R15 (доказуемость).
- **Критерий приёмки:** A17 (theory content pack criteria).
- **ADR:** ADR-008 (происхождение учебного контента).

## 1. Конкретный результат и зависимости

Разработать валидатор теоретических билетов `TheoryPackageValidator` и структуру подтверждения происхождения `ProvenanceRecord` в сборке `DS.Learning`:
- Проверка структуры `TheoryContentPack` из `Assets/DrivingSchool/Code/Contracts/Contracts.cs`:
  - Наличие и корректность `schemaVersion = 1`, `id`, `revision`, `source`.
  - Валидация каждого вопроса `TheoryQuestion`:
    - Уникальные строковые идентификаторы вопросов `id`.
    - Непустые поля текста вопроса `text`, темы `topic`, ссылки на ПДД `ruleReference` и объяснения `explanation`.
    - Массив вариантов ответов `answers` содержит от 2 до 5 вариантов (пустые строки запрещены).
    - Индекс верного ответа `correctIndex` строго входит в диапазон `[0 .. answers.Length - 1]`.
- Политика официальности:
  - Пакет с `isOfficial = true` допускается только при наличии подтвержденной записи `ProvenanceRecord` (юрисдикция, орган утверждения, дата редакции, разрешение на использование).
  - При отсутствии подтверждения пакет маркируется как авторский (`isOfficial = false`), а интерфейс не показывает плашку официального экзамена ГИБДД.

- **Контракт интерфейса:**
  ```csharp

  {
      public static ValidationResult Validate(TheoryContentPack pack);
      public static bool VerifyOfficialProvenance(TheoryContentPack pack, ProvenanceRecord provenance);
  }
  ```
- **Входы:** Экземпляр `TheoryContentPack` (например, загруженный из `Assets/StreamingAssets/Examples/theory.json`).
- **Выходы:** `ValidationResult` со списком ошибок и предупреждений.

## 4. Примеры данных и ожидаемого поведения

- Валидация штатного авторского примера `theory.json`:
  - 1 вопрос, 3 варианта ответа, `correctIndex = 0`.
  - Все поля заполнены, `isOfficial = false`.
  - Валидатор возвращает `IsValid = true`, пакет допускается к использованию в учебном модуле.

## 5. Отрицательные сценарии

- **Выход индекса верного ответа за пределы:** Если `answers.Length == 3`, а `correctIndex = 5`, валидатор отклоняет пакет с `InvalidDataException("correctIndex out of bounds")`.
- **Попытка объявить себя официальным билетом без доказательств:** Пакет с `isOfficial = true`, у которого `source` пуст или отсутствует `ProvenanceRecord`, отклоняется политикой целостности.
- **Дублирование ID вопросов:** Наличие двух вопросов с одинаковым `id` в одном пакете отклоняется.
- **Пустой вариант ответа:** Наличие строки `""` или пробелов среди вариантов ответа запрещено.
