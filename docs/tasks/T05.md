# T05 — Калибровка руля и педалей G27 (Wheel Calibration Profile)

- **Требования:** R02 (руль G27, педали, калибровка), R15 (доказуемость).
- **Критерий приёмки:** A04 (input criteria).
- **ADR:** ADR-005 (семантика ввода и G27).

## 1. Конкретный результат и зависимости

Создать структуры и логику калибровки игрового руля `WheelCalibrationProfile` и адаптер `WheelCalibrationService`:
- Нормализация 3 независимых педалей (сцепление, тормоз, газ) с индивидуальными диапазонами min/max, мёртвыми зонами (deadzone) и флагом инверсии (inversion).
- Нормализация угла руля: 900° (от −450° до +450°), определение центра, линейность / кривая чувствительности.
- Поддержка H-образного шифтера (6 передач вперед + 1 назад через нажатие рычага).
- Сохранение и загрузка профиля калибровки в JSON через изолированный persistence.

## 3. Точные входы, выходы и контракты

- **Контракт профиля:**
  ```csharp
  [System.Serializable]
  public class AxisCalibration
  {
      public float rawMin = 0f;
      public float rawMax = 1f;
      public float deadzone = 0.02f;
      public bool inverted = false;
      public float Normalize(float raw);
  }
  ```
- **Вход:** Сырые значения осей DirectInput / Unity Input System.
- **Выход:** Нормализованный `DriverCommand` со значениями строго в физических границах: руль `[-1..1]`, педали `[0..1]`.

## 4. Примеры данных и ожидаемого поведения

- Сырая педаль Logitech выдает 1.0 в ненажатом состоянии и −1.0 при полном нажатии (`inverted = true`):
  - При `raw = 1.0` результат `Normalize` равен `0.0`.
  - При `raw = -1.0` результат `Normalize` равен `1.0`.
  - При `raw = 0.0` результат `Normalize` равен `0.5`.
- Мертвая зона 5%: при отклонении сырого значения менее 5% от нулевого положения возвращается строго `0.0`.

## 5. Отрицательные сценарии

- **Совпадение rawMin и rawMax:** Если в профиле задано `rawMin == rawMax` (ошибка калибровки), метод нормализации не должен делить на ноль или выдавать NaN/Infinity; он обязан вернуть безопасное значение `0.0` и залогировать предупреждение.
- **Поврежденный файл профиля:** При чтении битого JSON профиля калибровки сервис должен загружать безопасный дефолтный профиль с записью ошибки в лог, не блокируя запуск приложения.
- **Отключение руля в процессе:** При физическом отключении устройства (`IsConnected == false`) оси не должны «застревать» в максимальном газе; все управляющие воздействия сбрасываются в нейтраль.
