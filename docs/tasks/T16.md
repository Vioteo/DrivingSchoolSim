# T16 — Агент движения по полосе графа (Lane Follower AI Agent)

- **Требования:** R09 (трафик следует тем же полосам графа), R15 (доказуемость).
- **Критерий приёмки:** A11 (agents & traffic behavior).
- **ADR:** ADR-003 (единый roadgraph для игрока и AI), ADR-001 (pure core).

## 1. Конкретный результат и зависимости

Разработать алгоритм движения трафика по полосе `LaneFollowerAgent` в сборке `DS.Simulation`:
- Следование строго по осевой линии назначенной полосы `Lane` дорожного графа:
  - Алгоритм Pure Pursuit / Stanley Controller для вычисления угла поворота руля по упреждающей точке (lookahead point, зависящей от скорости).
- Продольный контроль скорости и дистанции (Intelligent Driver Model):
  - Поддержание скорости в пределах скоростного лимита сегмента `speedLimitKph`.
  - Плавное замедление и остановка при обнаружении препятствия впереди на полосе (другой автомобиль, затор, пешеход) с выдерживанием дистанции остановки 2.5 м.
- Переход на следующую полосу: корректное продолжение движения по цепочке связей `successors` на перекрестках без рывков и телепортаций.
- Остановка перед запрещающим сигналом светофора / стоп-линией.

## 3. Точные входы, выходы и контракты

- **Контракт интерфейса:**
  ```csharp
  public class LaneFollowerAgent
  {
      public double CurrentDistanceAlongLane { get; }
      public float CurrentSpeedMps { get; }
      public float TargetSteeringAngleRad { get; }
      public float TargetAccelerationMps2 { get; }
      public void Update(float dtSeconds, float distanceToLeadObstacleM, bool isStopLineActive);
      public void SwitchToLane(Lane newLane);
  }
  ```
- **Входы:** Шаг времени `dt`, дистанция до лидирующего препятствия, статус стоп-линии.
- **Выходы:** Ускорение/замедление `TargetAccelerationMps2`, угол руления `TargetSteeringAngleRad`.

## 4. Примеры данных и ожидаемого поведения

- Свободная дорога (лимит 60 км/ч = 16.67 м/с):
  - Агент плавно разгоняется с ускорением не более 1.8 м/с² до целевой скорости 16.67 м/с.
  - Боковое отклонение от центра полосы на прямом участке не превышает 0.05 м.
- Препятствие на расстоянии 20 м при скорости 10 м/с:
  - Агент начинает комфортное торможение (замедление 2.0 м/с²), останавливается ровно за 2.5 м до препятствия и удерживает нулевую скорость.

## 5. Отрицательные сценарии

- **Красный сигнал светофора:** При `isStopLineActive = true` агент обязан остановиться строго перед стоп-линией без выезда за ее пределы (допуск переезда ≤ 0.2 м).
- **Конец цепочки полос (отсутствие successor):** Агент обязан распознать тупик полосы заранее и плавно остановиться в конце сегмента, не падая с `IndexOutOfRangeException`.
- **Резкий занос лидирующего объекта:** При резком торможении лидера агент применяет экстренное торможение (до −5 м/с²), предотвращая лобовое столкновение.

## Дополнение (ADR-012, 24.09.2026)

Агент хранит поперечное смещение `d` от осевой линии полосы, а не только `s`: `Update` принимает целевое `d` от поведенческого слоя T34 (перестроение, объезд) и ограничивает скорость его изменения. В этой карточке целевое `d` всегда 0, но контракт должен его поддерживать, чтобы T34 не переписывал агента. Препятствие впереди определяется по участникам, чьи габариты пересекают коридор агента с учётом `d`, а не по одной полосе.
