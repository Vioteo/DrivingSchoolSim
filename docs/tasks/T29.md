# T29 — Раскладка района и компилятор графа (District Layout & Graph Compiler)

- **Требования:** R07, R15.
- **Критерий приёмки:** A07, A09 (часть «одна модель для mesh/AI/rules»).
- **ADR:** ADR-003, ADR-011. Дизайн: [city.md](../city.md#конвейер-сборки).
- **Зависит от:** T27, T28.

## 1. Конкретный результат и зависимости

- DTO `DistrictLayout`: экземпляры модулей (`id`, `catalogId`, поза или «пристыковать сокет X к сокету Y экземпляра Z»), параметры экземпляров (ограничение скорости, приоритет въездов, план светофора, знаки поверх шаблона).
- Pure C# `DistrictCompiler.Compile(DistrictLayout, templates, signCatalog) → WorldDocumentV2`: разворачивает шаблоны в мировые координаты (double), сшивает полосы по стыкам, вычисляет зоны действия знаков, прогоняет `WorldValidatorV2`.
- Выход детерминирован: одинаковый вход даёт побайтно одинаковый JSON (стабильный порядок, стабильные `id` вида `<instanceId>/<localId>`).

Перед реализацией решить и записать в карточку, где живёт компилятор: `DS.World` (сейчас с UnityEngine из-за JsonUtility) или новый pure-модуль. Если новый asmdef — согласовать с владельцем проекта.

## Реализация (24.09.2026)

Компилятор и вся логика графа живут в `DS.Simulation` (`Simulation/RoadGraph/`), без нового asmdef: `DS.World` зависит от UnityEngine, а новый asmdef перезаписал бы `tools/setup_project.py`. Размещение модулей — явные позы в раскладке; для авторинга есть `DistrictCompiler.Dock`, вычисляющий позу нового модуля по сокету соседа.

## 4. Примеры данных и ожидаемого поведения

- Крест + 2 прямые 20 м на северном рукаве: полосы прямых сшиты с полосами креста, у северной входящей полосы есть преемники прямо, направо и налево.
- Знак 3.24 «40», поставленный на прямой, действует до стоп-линии ближайшего перекрёстка.

## 5. Отрицательные сценарии

- Стыки не совпадают по положению (> 1 см) или направлению (> 0,1°) → ошибка с `id` обоих экземпляров.
- Стыкуются разные профили (1+1 к 2+2) без переходного модуля → ошибка.
- Висячий стык внутри района без явной пометки «край района» → ошибка.
- Замкнутая петля из текущих модулей, не сходящаяся на 4 м (см. city.md), → ошибка компилятора с величиной невязки, а не сдвиг модулей.
