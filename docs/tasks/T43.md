# T43 — Модель и экран настроек

- **Требования:** R01 (UI). **Приёмка:** A03. **ADR:** ADR-016. **Спецификация:** `docs/ui-settings.md`, макет `artifacts/visual-review/settings/index.html`.

## Результат

- **Модель — `DS.Settings`** (`Code/Settings/`, чистый C#, `noEngineReferences`): `GameSettings` (разделы graphics/controls/audio/gameplay, `version`), `SettingsSchema` (вкладки, группы, пункты, тексты справки, флаги, ручное сопоставление ключей с полями), `SettingsValidator.Sanitize`, `SettingsMigrator`, `SettingsSession` (черновик, изменённые пункты, пресет качества, сброс пункта/вкладки, откат режима экрана), `SettingsService` (применённые настройки + событие `Applied`).
- **Файл** — `SettingsStore`: `Application.persistentDataPath/settings.json` (у владельца `…/AppData/LocalLow/DrivingSchool/DrivingSchoolSim Prototype/settings.json`). Нет файла → значения по умолчанию; битый → по умолчанию + предупреждение; вне диапазона → обрезка; запись через `.tmp` и замену.
- **Применение** — `SettingsRuntime` загружает файл до первой сцены. `SettingsApplier` (UI): режим экрана и разрешение (в редакторе только лог), V-Sync и лимит FPS, тени и MSAA URP (в редакторе откатываются при выходе из Play — ассет не меняется), FXAA/SMAA и тени на камерах, тема, общая громкость, звук в свёрнутом окне; `UIScaleFollower` — масштаб всех UI-канвасов. `DriveSettingsApplier` (Presentation): FOV из салона, дальность прорисовки, вид при старте, качество зеркал (256/512/1024, с пересозданием текстур на лету), скорость руления с клавиатуры, КПП при старте поездки.
- **Экран** — `Settings.prefab` (генератор **Driving School → Build Settings screen**, входит в *Build UI Prefabs*), `SettingsScreenController` + `SettingsRowView`. Вход: «Настройки» в главном меню и новый пункт «Настройки» в паузе. Вкладки Графика / Управление / Звук / Обучение, справка справа, «По умолчанию / Отменить / Применить», «Изменено параметров: N», точка у изменённого пункта.
- Управление: ↑↓ пункт (вниз с последнего — на кнопки), ←→ значение (повтор при удержании), Q/E вкладка, R сброс пункта, Enter переключить/выбрать, Esc назад. Геймпад: крестовина, A, B, Y, бамперы. Мышь: наведение, клики, стрелки, перетаскивание ползунков, колесо.
- Диалоги: «Сохранить изменения?» (Остаться / Не сохранять / Сохранить), «Сбросить вкладку?», «Оставить этот режим экрана?» с обратным отсчётом 15 с и автооткатом.

## Отличия от макета

- Значения по умолчанию «Качества» = пресет «Высокое»: тени «Высокие», SMAA, 1200 м (в макете 2/2/800 не совпадали ни с одним пресетом). Пресеты: Низкое (Низкие, выкл., 400 м), Среднее (Средние, FXAA, 800 м), Высокое (Высокие, SMAA, 1200 м). «Средние» тени = прежние значения URP.asset (50 м, 2048, 1 каскад).
- FOV по умолчанию 75° (было зашито 68° в `DriverCameraRig`).
- Стрелки ◀ ▶ и кружки — спрайты `Art/UI/Triangle.png`, `Circle.png` (в шрифте Golos их нет).
