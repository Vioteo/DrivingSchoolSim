# T36 — Пешеходы на тротуарах и Unity-адаптер (Sidewalk Pedestrians & Animation)

- **Требования:** R09.
- **Критерий приёмки:** A11.
- **ADR:** ADR-001, ADR-012. Дизайн: [city.md](../city.md#пешеходы-t17-t36).
- **Зависит от:** T17 (переход), T27 (тротуары), T30, T35 (пешеходы регистрируются в диспетчере), T40 (переход — запрос `PedestrianCross`, машины получают `YieldToPedestrian`).

## 1. Конкретный результат и зависимости

- Pure C# `PedestrianSimulation`: маршруты по сети тротуаров, движение в координатах `(s, d)` полилинии, расхождение и обгон смещением `d`, простое расталкивание; на переходе — автомат T17. Плотность из данных, **первый профиль: до 10 пешеходов на район**.
- Unity-адаптер `PedestrianView`: пул префабов `DS_Pedestrian_A/B/C`, Animator с клипами Idle/Walk из рига, скорость воспроизведения по фактической скорости (без «скольжения» ног), kinematic-коллайдер.
- Наезд на пешехода — событие для правил и стоп агента. Рэгдолл не входит.

## 2. Разрешённая область изменений

- `Assets/DrivingSchool/Code/Simulation/Traffic/PedestrianSimulation.cs`
- `Assets/DrivingSchool/Code/Presentation/PedestrianView.cs`
- `Assets/DrivingSchool/Code/Tests/PedestrianSimulationTests.cs`
- Настройка Animator — через `PedestrianAssetBuilder`, не в Inspector (art-pipeline.md).
- Файловый бюджет: 2 production files + изменение билдера + 1 test file.

## 3. Точные входы, выходы и контракты

- Переход занят для ИИ и правил, пока хотя бы один пешеход на проезжей части (`IsOnRoadway` из T17).

## 4. Примеры данных и ожидаемого поведения

- Два пешехода навстречу на тротуаре 2 м: расходятся без пересечения капсул.
- Регулируемый переход: пешеходы ждут зелёного даже без машин.

## 5. Отрицательные сценарии

- Пешеход не сходит с тротуара вне перехода (в v0 нет «перебегающих»; это отдельная сценарная карточка позже).
- Пешеход не появляется в поле зрения игрока.

## 6. Команда проверки и доказательства

```powershell
& $dsUnity -batchmode -nographics -projectPath $dsProject -runTests -testPlatform EditMode -testFilter "DrivingSchool.Tests.PedestrianSimulationTests" -testResults "$dsProject/artifacts/reports/pedestrian-sim-tests.xml" -logFile "$dsProject/artifacts/reports/pedestrian-sim-tests.log"
```

C05: видео Play Mode, пешеходы на регулируемом и нерегулируемом переходе.

## 7. Условия завершения

- Тесты проходят (exit code 0); видео показывает анимацию без скольжения ног.
