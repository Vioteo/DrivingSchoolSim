# T53 — Экран заданий

Оба режима запускаются через «Задания»: пошаговый урок «Начало движения» и свободная тестовая площадка. Выбор показывает описание, запуск выполняется отдельной кнопкой. Назад возвращает фокус в главное меню. Мышь, стрелки/крестовина, Tab/Shift+Tab, Enter и Esc.

UI передаёт намерение MainMenuFlow → AppNavigator. Свободная поездка сбрасывает LessonLaunch.LessonId. Недоступная сцена не запускается. Старый пункт «Продолжить занятие» не сохранял прогресс и заменяется каталогом.

Менять UIBuilder, затем на чистом дереве выполнить UIBuilder.BuildAssignmentsUI; результат отдельным gen-коммитом. Приёмка: тесты выбора/возврата/навигации, запуск обоих режимов из UI, полный tools/check.ps1 и визуальная проверка.
