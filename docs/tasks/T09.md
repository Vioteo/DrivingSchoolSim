# T09 — Коробка передач: МКПП и АКПП (Gearbox Simulation Model)

- **Требования:** R04 (МКПП и АКПП), R15 (доказуемость).
- **Критерий приёмки:** A06 (drivetrain criteria).
- **ADR:** ADR-007 (калибруемая динамика), ADR-001 (pure core).

## 1. Конкретный результат и зависимости

Разработать модель коробки переключения передач `GearboxModel` в сборке `DS.Simulation`:
- **Ручной режим (МКПП):**
  - Прямой выбор передач: `-1` (задний ход), `0` (нейтраль), `1..6` (передачи вперед).
  - Передаточные числа из `vehicle.json`: `[3.6, 2.1, 1.4, 1.05, 0.84, 0.69]`, задняя `-3.5`, главная пара `4.1`, КПД `0.9`.
  - На нейтрали (`requestedGear = 0`): крутящий момент на колеса строго 0 Нм.
  - На задней передаче: знак крутящего момента инвертируется (отрицательный).
- **Автоматический режим (АКПП):**
  - Режимы селектора: P (Parking), R (Reverse), N (Neutral), D (Drive).
  - Автоматическое повышение передачи при оборотах двигателя выше 2500 rpm и понижение при оборотах ниже 1300 rpm.
  - Блокировка включения P и R при движении вперед со скоростью выше 2 м/с.

## 3. Точные входы, выходы и контракты

- **Контракт интерфейса:**
  ```csharp
  public enum TransmissionType { Manual, Automatic }
  public enum AutomaticSelector { P, R, N, D }

  public class GearboxModel
  {
      public int CurrentGear { get; }
      public float CurrentRatio { get; }
      public float AxleTorqueNm { get; }
      public float InputShaftRpm { get; }
      public void UpdateManual(float clutchTorqueNm, int requestedGear, float wheelAngularVelocityRadSec);
      public void UpdateAutomatic(float engineTorqueNm, float engineRpm, AutomaticSelector selector, float vehicleSpeedMps, float dtSeconds);
  }
  ```
- **Входы:** Момент от сцепления/гидротрансформатора, запрошенная передача/селектор, угловая скорость колес.
- **Выходы:** `AxleTorqueNm`, `InputShaftRpm`, `CurrentGear`.

## 4. Примеры данных и ожидаемого поведения

- **1-я передача МКПП:**
  - При `clutchTorqueNm = 100 Нм`: `AxleTorque = 100 * 3.6 * 4.1 * 0.9 = 1328.4 Нм`.
- **Задний ход МКПП:**
  - При `clutchTorqueNm = 100 Нм`: `AxleTorque = 100 * (-3.5) * 4.1 * 0.9 = -1291.5 Нм`.
- **Нейтраль МКПП:**
  - При любых оборотах и моменте сцепления: `AxleTorque = 0.0 Нм`.

## 5. Отрицательные сценарии

- **Недопустимый номер передачи:** При запросе передачи 7 или −2 выбрасывается `ArgumentOutOfRangeException`.
- **Включение Park на ходу:** Попытка перевести селектор АКПП в P на скорости 15 км/ч должна игнорироваться (оставаться в D/N) с фиксацией защитного отказа, чтобы не вызывать мгновенную остановку симулятора с бесконечной силой.
- **Движение задним ходом на АКПП:** При включении D во время отката назад сцепление/гидротрансформатор должны плавно гасить отрицательную скорость без расхождения в расчетах.
