# T03 — Экран uGUI/TMP (UI Migration Baseline)

- **Требования:** R01 (uGUI/TMP, платформа), R15 (доказуемость).
- **Критерий приёмки:** A03 (UI).
- **ADR:** ADR-006 (стенд vs production UI).

## 1. Конкретный результат и зависимости

Перенести первый экран из HTML-прототипа в нативный интерфейс Unity на базе **uGUI** и **TextMeshPro**:
- Целевой экран: **Главное меню (Home)** по утверждённому макету `artifacts/visual-review/settings/index.html` (24.09.2026): «Продолжить занятие», «Занятия», «Теория ПДД», «Экзаменационный маршрут» (недоступен, бейдж «скоро»), «Настройки», «Выход».
- Поддержка двух целевых разрешений: 1920×1080 и 1280×720 (Canvas Scaler: Scale With Screen Size, Match Width/Height 0.5, reference 1920×1080).
- Настройка шрифта TextMeshPro с полным набором русских глифов (Cyrillic character set).
- Навигация с клавиатуры (стрелки, Enter, Escape, Tab) через `InputSystemUIInputModule`; кнопки G29 — по `docs/ui-settings.md` §6 (раскладка — T28).

## 2. Разрешённая область изменений

- `Assets/DrivingSchool/Code/Presentation/UI/MainMenuController.cs` (новый контроллер)
- Префаб `Assets/DrivingSchool/Prefabs/UI/MainMenu.prefab`
- Ресурсы шрифтов TMP в `Assets/DrivingSchool/Art/Fonts/`
- Файловый бюджет: ≤ 3 production files + 1 test file.
- **Фактически (24.09.2026):** модуль `Code/Presentation/UI/` (`DS.Presentation.UI.asmdef`, `MainMenuController.cs`, `MenuItemView.cs`, `UITheme.cs`, `ThemedGraphic.cs`), генератор `Code/Editor/UIBuilder.cs`, шрифты `Art/Fonts/`, тест `Code/Tests/UITests.cs`, ссылки в `DS.Editor`/`DS.Tests` asmdef и `tools/setup_project.py`. Бюджет превышен: тема и вид пункта меню — отдельные MonoBehaviour/ScriptableObject, Unity требует для них собственные файлы.

## 3. Точные входы, выходы и контракты

- **Входы:** тема «Асфальт» (`docs/ui-settings.md` §8, ассет `Data/UI/Themes/UITheme_Asphalt.asset`), шрифт Golos Text + Roboto Mono (`Art/Fonts/SOURCES.md`). Прежние токены prototype.css (`#14191e`/`#1c252d`/`#8ebfe1`) отменены.
- **Выходы:** Префаб `MainMenu.prefab` с инспектируемым контроллером `MainMenuController`, отправляющим события намерения (`OnStartLessonRequested`, `OnSelectLessonRequested`, `OnTheoryRequested`, `OnSettingsRequested`, `OnExitConfirmed`).
- **Контракт:** UI не управляет физикой или `LessonSession` напрямую — только генерирует события для координатора приложения.

## 4. Примеры данных и ожидаемого поведения

- При нажатии клавиши Tab фокус перемещается между кнопками меню; активная кнопка получает рамку подсветки (`#8ebfe1`).
- При нажатии Enter на кнопке «Продолжить» вызывается назначенное событие UnityEvent.
- При разрешении 1280×720 текст не выходит за границы панелей, многострочный перенос работает корректно, знаки многоточия отсутствуют.

## 5. Отрицательные сценарии

- **Отсутствие символов в шрифте:** Если в тексте встречаются русские буквы (например, «Уверенность за рулём»), они не должны превращаться в квадраты (`missing glyph placeholder`). Шрифт TMP обязан содержать диапазон `0x0400-0x04FF`.
- **Потеря фокуса:** Нажатие стрелок вне диапазона кнопок не должно приводить к `NullReferenceException` или деактивации навигации.
- **Escape:** Нажатие Escape на главном экране не закрывает приложение без подтверждения.


- Скриншоты префаба в Game View при 1920×1080 и 1280×720 (`artifacts/reports/ugui-home-1920.png`, `ugui-home-1280.png`).
- Запись успешного теста инициализации TMP и Canvas.

## 7. Условия завершения

- Создан префаб `MainMenu.prefab` в uGUI/TMP.
- Поддерживается кириллица без артефактов и квадратов.
- Клавиатурный фокус перемещается по всем интерактивным кнопкам.
- Контроллер компилируется без предупреждений.
