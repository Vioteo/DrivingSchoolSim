# T10 — Адаптер физики автомобиля Unity (Unity Vehicle Physics Adapter)

- **Требования:** R04 (учебная динамика), R05 (автомобиль), R15 (доказуемость).
- **Критерий приёмки:** A06 (drivetrain), A02 (asset check).
- **ADR:** ADR-001 (pure core и Unity adapters), ADR-007 (калибруемая динамика).

## 1. Конкретный результат и зависимости

Создать компонент `VehiclePhysicsAdapter` в слое адаптеров Unity (`Assets/DrivingSchool/Code/Presentation/Physics/`):
- Связывает чистый математический расчет силовой передачи (`EngineModel`, `ClutchModel`, `GearboxModel` из pure `DS.Simulation`) с `Rigidbody` Unity в `FixedUpdate` (100 Гц).
- Применяет крутящий момент к ведущим колесам (задний привод) и тормозные моменты:
  - Рабочий тормоз: распределение 65% на переднюю ось, 35% на заднюю ось.
  - Стояночный тормоз (`handbrake = true`): 100% блокировка задних колес.
- Геометрия руления: поворот передних колес с кинематикой Аккермана (внутреннее колесо поворачивается на больший угол, предельный угол ±32°).
- Формирует и публикует структуру `VehicleState` для отображения и правил в каждом физическом тике.

## 3. Точные входы, выходы и контракты

- **Входы:** `DriverCommand` от `IInputSource`, параметры кузова и массы из `vehicle.json` (масса 1350 кг, колесная база 2.72 м, центр масс `[0, 0.51, -0.1]`).
- **Выходы:** `VehicleState`:
  ```csharp
  public struct VehicleState
  {
      public long tick;
      public double simulationSeconds;
      public float signedSpeedMps;
      public float engineRpm;
      public float steeringRadians;
      public float clutchTorqueNm;
      public int gear;
      public EnginePhase engine;
      public bool leftIndicator, rightIndicator, lowBeam, highBeam, brakeLight;
  }
  ```
- **Интеграция:** Rigidbody.mass = 1350, centerOfMass = new Vector3(0, 0.51f, -0.1f).

## 4. Примеры данных и ожидаемого поведения

- **Трогание с места:**
  - Включена 1-я передача, двигатель работает (850 rpm), плавное отпускание сцепления (`clutch` от 1.0 до 0.0) при небольшом газе (`throttle = 0.2`) разгоняет автомобиль вперед без заглохания.
  - Скорость `signedSpeedMps` плавно возрастает, становясь положительной.
- **Остановка на подъеме (Hill Start):**
  - Автомобиль на эстакаде уклоном 10%. При зажатом ручнике (`handbrake = true`) автомобиль удерживается неподвижно на уклоне без отката назад (`speed == 0`).
  - При создании достаточного момента на колесах и отпускании ручника автомобиль начинает движение вверх.

## 5. Отрицательные сценарии

- **Бросок сцепления на холостых:** Если резко бросить сцепление (`clutch = 0`) на 1-й передаче без нажатия газа при неподвижном автомобиле, двигатель обязан заглохнуть (`engine = EnginePhase.Stalled`), а автомобиль должен совершить резкий клевок и остановиться.
- **Взрыв физики при коллизии:** При столкновении с препятствием силы контакта не должны вызывать скачков скорости до NaN/Infinity или проваливания сквозь геометрию асфальта.
- **Несимметричность Аккермана:** При повороте налево угол левого колеса больше угла правого; при повороте направо — угол правого больше угла левого.

## 7. Условия завершения

- Создан адаптер `VehiclePhysicsAdapter`, корректно изолирующий Unity Rigidbody от pure solver.
- Автомобиль трогается, разгоняется, тормозит и удерживается ручником.
- Публикуемый `VehicleState` содержит корректные обороты, передачу и скорость.
- Тесты проходят с exit code 0.
