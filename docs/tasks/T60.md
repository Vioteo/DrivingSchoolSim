# T60 — Боты: руль, кузов, лёгкие аварии, сбитый пешеход

Статус: PASS (EditMode: TrafficBodyTests 4/4, PedestrianSimulationTests 7/7, ManeuverProtocolTests вместе с AStaleLeaseDoesNotHangThePlayersClaim, RoadKitClearanceTests — 19/19). Play: игрок на 32 км/ч сбивает двух пешеходов на переходе X1 — рэгдоллы лежат перед машиной, симуляция `Down`, Unity не зависает (снимок `artifacts/visual-review/t60-district/pedestrian-hit-side.png`).
Код T60–T62 частично попал в контрольную точку другой сессии `166be2e` («T50, T51»); остальное — ветка `feat/T60-city-traffic`.

## Проблема (от пользователя)
Машины ботов «едут по линии», колёса не поворачивают; после лёгкой аварии застревают навсегда; пешехода нельзя сбить.

## Сделано
- `LaneFollowerAgent`: передняя ось идёт по траектории, задняя тянется за ней (трактриса). Кузов (`BodyPosition`,
  `BodyHeadingRad`) срезает поворот внутрь; угол колёс `WheelSteerRad` ≤ 35°.
- `TrafficVehicleView`: клевок/крен кузова на пружине (1.6 Гц, демпфирование 0.6; ±4°/±5°), передние колёса поворачивают.
- Касание (`ReportContact`) → бот 5 с стоит с аварийкой (`HazardHoldSeconds`) и едет дальше; пока давят — стоит.
- Пешеход: рэгдолл на 20 костях (`PedestrianRagdoll`, 70 кг), удар машиной > 1.2 м/с → падает с импульсом машины;
  в симуляции фаза `Down`, переход занят, боты останавливаются перед лежащим; убирается через 90 с.
  `TrafficDirectorHost.PedestrianHit` / `HitPedestrians` — для инструктора и штрафов (подключение — отдельно).
- Выгрузка чанков: машина убирается и по точке на пути, и по кузову.
- **Зависание (найдено в Play):** `ClaimForPlayer` крутил вечный цикл, если аренда бота пережила его разрешение
  (перестроение прямо перед X1) — Unity замерзал, когда игрок въезжал в перекрёсток. Исправлено
  (`ReservationTable.ReleaseConflicting`, каждый владелец один раз), тест с таймаутом в отдельном потоке.
