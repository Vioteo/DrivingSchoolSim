# T04 — Адаптер клавиатурного ввода (Keyboard Input Adapter)

- **Требования:** R02 (ввод клавиатуры), R15 (доказуемость).
- **Критерий приёмки:** A04 (input adapter criteria).
- **ADR:** ADR-005 (семантика ввода), ADR-001 (pure core и адаптеры).

## 1. Конкретный результат и зависимости

Реализовать класс `KeyboardInputSource`, реализующий интерфейс `IInputSource` в сборке `DS.Input`:
- Преобразование клавиш в структуру `DriverCommand`:
  - Руль: A / D или Left / Right Arrow (с настраиваемой скоростью нарастания `steeringRate` и возврата в ноль `returnRate`).
  - Педали: W (газ 0..1), S (тормоз 0..1), Space (ручник), Shift / Ctrl (сцепление 0..1).
  - Передачи: 1–6 (передачи 1–6), R (задний ход = −1), N (нейтраль = 0).
  - Зажигание и стартер: I (зажигание), E (стартер).
- Все значения полей `DriverCommand` обязаны проходить метод `DriverCommand.Validate()` без исключений.

## 3. Точные входы, выходы и контракты

- **Интерфейс:** `DrivingSchool.Contracts.IInputSource`:
  ```csharp
  public interface IInputSource
  {
      DriverCommand Read(long tick);
      bool IsConnected { get; }
  }
  ```
- **Вход:** `long tick` (номер шага симуляции).
- **Выход:** Валидный экземпляр `DriverCommand` со всеми finite-значениями.

## 4. Примеры данных и ожидаемого поведения

- Удержание клавиши D в течение 0.5 с при `steeringRate = 2.0/s`: steering плавно возрастает от 0.0 до 1.0 и останавливается на 1.0 (зажим `Mathf.Clamp(v, -1f, 1f)`).
- Отпускание клавиши: steering плавно возвращается к 0.0.
- Нажатие клавиши '3': `requestedGear = 3`.
- При вызове `Read(tick)` поле `sequence` совпадает с переданным тиком или монотонно возрастает.

## 5. Отрицательные сценарии

- **Одновременное нажатие противоположных клавиш:** При одновременном нажатии A и D угол руления обязан стремиться к 0.0, а не вызывать дергания или NaN.
- **Одновременное нажатие газа и тормоза:** Газ и тормоз должны передавать свои фактические степени нажатия (например, throttle=1.0, brake=1.0) без сбоя в `Validate()`, так как ситуация одновременного нажатия двух педалей возможна и обрабатывается в логике сцепления/тормозов.
- **Потеря фокуса окна:** При `OnApplicationFocus(false)` все аналоговые оси педалей и газа обязаны сбрасываться в 0 (газ=0, тормоз=0, сцепление=0), чтобы исключить «залипание» акселератора.

## 7. Условия завершения

- Класс `KeyboardInputSource` компилируется в `DS.Input`.
- Все тесты `KeyboardInputTests` завершаются со статусом `Passed`.
- Исключена передача NaN/Infinity и выход за диапазоны `[-1..1]` для руля и `[0..1]` для педалей.
