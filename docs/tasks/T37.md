# T37 — Таблица ошибок экзамена как данные (Exam Penalty Table)

- **Требования:** R10, R15.
- **Критерий приёмки:** A12.
- **ADR:** ADR-008, ADR-013.

## 1. Конкретный результат и зависимости

- Файл `Assets/DrivingSchool/Data/Rules/exam-penalties.json`: перечень ошибок из **Приложения 5 к Административному регламенту МВД** (приказ МВД России от 20.02.2021 № 80) в **последней доступной редакции**. На 24.09.2026 последняя найденная редакция — от 26.05.2025 (изменения приказом МВД № 315); перед переносом исполнитель проверяет, нет ли более новой.
- Заголовок пакета: документ, редакция, дата сверки, URL источника (официальное опубликование `publication.pravo.gov.ru` или справочно-правовая система), кто сверял.
- Строка: шифр/номер ошибки из приложения, текст как в источнике, баллы, признак немедленного прекращения экзамена, ссылки на пункты ПДД (если есть в тексте), поле `implementedBy` (ruleId или пусто).
- Порог «экзамен не сдан» и правила суммирования — тоже из текста регламента, с номером пункта.
- DTO и валидатор пакета; `TrafficRules`, `SpeedLimitEvaluator` и курс площадки переводятся на ссылки по шифру отдельными итерациями (это не часть первой итерации).

**Нельзя** заполнять таблицу по пересказам из блогов. Если официальный текст получить не удалось — статус BLOCKED, а не данные «по памяти».

## 2. Разрешённая область изменений

- `Assets/DrivingSchool/Data/Rules/exam-penalties.json`
- `Assets/DrivingSchool/Code/Contracts/ExamPenaltyTable.cs`
- `Assets/DrivingSchool/Code/Rules/ExamPenaltyTableValidator.cs`
- `Assets/DrivingSchool/Code/Tests/ExamPenaltyTableTests.cs`
- `docs/data-formats.md`
- Файловый бюджет: 2 production files + данные + 1 test file + документ.

## 3. Точные входы, выходы и контракты

```csharp
public sealed class ExamPenaltyTable { public string document, revision, reviewedOn, sourceUrl; public ExamPenalty[] items; }
public sealed class ExamPenalty { public string code, text; public int points; public bool terminatesExam; public string[] pddRefs; public string implementedBy; }
```

## 4. Примеры данных и ожидаемого поведения

- Сумма баллов и прекращение экзамена считаются только по таблице; тест проверяет пример из текста регламента.

## 5. Отрицательные сценарии

- Дубликат шифра, пустой текст, баллы вне множества значений, встречающихся в источнике, пустая редакция или URL → ошибка валидации.
- `implementedBy` ссылается на несуществующий ruleId → ошибка.
