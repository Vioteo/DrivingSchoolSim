# T28 — Шаблоны семантики модулей дорожного набора (Road Kit Semantic Templates)

- **Требования:** R07, R15.
- **Критерий приёмки:** A07.
- **ADR:** ADR-011. Дизайн: [city.md](../city.md#шаблон-модуля).
- **Зависит от:** T27.

## 1. Конкретный результат и зависимости

Для каждого дорожного модуля `RK_Road_*` описать фрагмент графа в локальных координатах префаба и справочник знаков:
- `Assets/DrivingSchool/Art/RoadKit/semantics/<catalogId>.json`: стыки (положение, направление, профиль «полос туда / обратно, ширина полосы, тротуары»), полосы и связи с осевыми линиями, зоны конфликта, стоп-линии, переходы, тротуары, места под знаки и светофоры, типы разметки.
- `Assets/DrivingSchool/Data/Signs/sign-catalog.json`: код знака → `catalogId` префаба из Traffic Kit, тип (приоритет, запрет, предписание, информация), нужно ли значение. Коды — по ГОСТ Р 52290-2004; источник и редакция указываются в файле.
- Загрузчик и проверка шаблона (pure C#).

Первая итерация — только существующие модули: `RK_Road_Urban_20m`, `RK_Road_Curve90_R14`, `RK_Road_Cross_24m`. Модули из T39 получают шаблоны отдельными итерациями.

## 2. Разрешённая область изменений

- `Assets/DrivingSchool/Art/RoadKit/semantics/*.json`
- `Assets/DrivingSchool/Data/Signs/sign-catalog.json`
- `Assets/DrivingSchool/Code/World/ModuleTemplateLoader.cs`
- `Assets/DrivingSchool/Code/Tests/ModuleTemplateTests.cs`
- Файловый бюджет: 1 production file + данные + 1 test file.

## 3. Точные входы, выходы и контракты

- Координаты стыков, стоп-линий, переходов и бордюров берутся **из `tools/build_road_kit.py`** (например, крест: сокеты на ±12 м, проезжая часть ±4 м) и из `road-kit-export.json`, не на глаз. В шаблоне указывается SHA256 исходника, из которого сняты координаты.
- Оси — Unity (X вправо, Z вперёд), метры, корень префаба.

## 4. Примеры данных и ожидаемого поведения

- `RK_Road_Cross_24m`: 4 стыка, 8 входящих и выходящих полос (1+1 на каждом рукаве), 12 связей (прямо, направо, налево с каждого въезда, без разворота), 4 стоп-линии на правых входящих полосах, 4 перехода.
- Связь налево с юга и прямо с востока имеют общую зону конфликта.

## 5. Отрицательные сценарии

- SHA256 исходника в шаблоне не совпадает с текущим `catalog.json` → загрузчик сообщает «шаблон устарел».
- Осевая линия связи не начинается в конце входящей полосы (допуск 1 см) → ошибка.
- Две связи геометрически пересекаются, но не имеют общей зоны конфликта → ошибка.

## 6. Команда проверки и доказательства


## 7. Условия завершения

- Три существующих модуля имеют шаблоны; зоны конфликта креста вычислены и проверены тестом.
- Справочник знаков покрывает все знаки Traffic Kit v1.
- Все тесты проходят (exit code 0).
