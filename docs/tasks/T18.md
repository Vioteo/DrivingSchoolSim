# T18 — Оценка правил ПДД: скоростной режим и стоп-линия (Traffic Rule Evaluator)

- **Требования:** R10 (проверяемые правила и объяснимые события), R15 (доказуемость).
- **Критерий приёмки:** A12 (rules evaluation criteria).
- **ADR:** ADR-008 (происхождение учебного контента), ADR-001 (pure core).

## 1. Конкретный результат и зависимости

Разработать сервис проверки правил `RuleEvaluationService` и эвалюатор первого семейства правил `SpeedLimitRuleEvaluator` в сборке `DS.Rules`:
- Вход: текущий `VehicleState`, скоростной лимит активного сегмента `speedLimitKph`, параметры допуска.
- Фиксация нарушения скоростного режима:
  - Превышение лимита более чем на дельту допуска (`toleranceKph = 5.0 км/ч`, т.е. > 65 км/ч при знаке 60).
  - Фильтр дребезга (debounce duration): превышение должно длиться непрерывно более 1.5 секунды, чтобы исключить случайные микроскачки.
- Формирование структурированного события `RuleEvent`:
  - Строго **одно событие на переход границы** (edge-triggered event, а не спам событий каждый физический тик).
  - Заполнение всех полей: `id`, `ruleId = "RULE_SPEED_EXCEEDED"`, `ruleRevision = "2026.01"`, `participantId = "player"`, `evidenceId`, `explanationKey`, абсолютные координаты `x, y, z` в double, штрафные баллы `penalty`.
- Защита от дублирования при сдвиге начала координат (floating origin).

## 3. Точные входы, выходы и контракты

- **Контракт интерфейса:**
  ```csharp
  public interface IRuleEvaluator
  {
      string RuleId { get; }
      string RuleRevision { get; }
      void Evaluate(long tick, double simSeconds, VehicleState state, RoadSegment activeSegment, IList<RuleEvent> outEvents);
      void Reset();
  }
  ```
- **Выходной контракт:** `DrivingSchool.Contracts.RuleEvent`:
  ```csharp
  public struct RuleEvent
  {
      public string id, ruleId, ruleRevision, participantId, evidenceId, explanationKey;
      public double simulationSeconds, x, y, z;
      public int penalty;
  }
  ```

## 4. Примеры данных и ожидаемого поведения

- Сегмент со знаком 40 км/ч (11.11 м/с):
  - Машина разгоняется до 44 км/ч — нарушений нет (`tolerance = 5 км/ч`, порог 45 км/ч).
  - Машина разгоняется до 52 км/ч:
    - Секунды 1.0..2.4: накопление времени нарушения.
    - Секунда 2.5: генерируется строго одно событие `RuleEvent` с `penalty = 15`.
    - Секунды 2.6..5.0: машина продолжает ехать со скоростью 52 км/ч — новых событий не создается.
  - Машина замедляется до 38 км/ч: статус нарушения сбрасывается в `false`.
  - Повторный разгон выше 45 км/ч генерирует новое событие с новым уникальным `id`.

## 5. Отрицательные сценарии

- **Спам событий в каждом тике:** Если при скорости 70 км/ч эвалюатор создает 100 событий за одну секунду симуляции, тест падает с `AssertionException`.
- **Погрешность плавающей точки:** Скорость ровно 45.0001 км/ч при пороге 45 не должна генерировать хаотичные срабатывания туда-обратно (гистерезис сброса 2 км/ч).
- **Отсутствие сегмента (выезд за пределы дороги):** Если `activeSegment == null`, эвалюатор скорости не должен выбрасывать `NullReferenceException`.
