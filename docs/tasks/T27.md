# T27 — Пешеходы: дети, полицейский, анимации движения

- **Требования:** R09 (пешеходы), визуальная часть.
- **Связь:** T17 (логика перехода) использует эти модели через `PedestrianAnimator`.

## 1. Результат
- Генератор `tools/build_pedestrians.py` строит шесть моделей: трое взрослых (как раньше), двое детей, инспектор ДПС.
- Клипы: Idle, Walk, Run, LookAround у гражданских; Idle, Walk, LookAround и три жеста регулировщика у полицейского.
- Unity: `PedestrianAssetBuilder` собирает контроллер с blend tree по скорости, `PedestrianAnimator` подаёт в него скорость из движения.

## 2. Разрешённая область изменений
- `tools/build_pedestrians.py`, `tools/verify_pedestrians.py`
- `ArtSource/Pedestrians/*`, `Assets/DrivingSchool/Art/Pedestrians/*`, `Materials/Pedestrians/*`
- `Code/Editor/PedestrianAssetBuilder.cs`, `Code/Presentation/PedestrianAnimator.cs`
- `docs/pedestrians.md`, `artifacts/reports/pedestrians-*`, `artifacts/visual-review/pedestrians/*`

## 3. Проверка
1. `blender -b --python tools/build_pedestrians.py` → `PEDESTRIANS_GENERATED`.
2. `blender -b --python tools/verify_pedestrians.py` → `PEDESTRIANS_EXPORT_PASS` (хэши, рост, шов цикла < 2 мм, движение, пол на 31 кадре каждого клипа, FBX и GLB).
3. `PedestrianAssetBuilder.Build` в Unity → `PEDESTRIAN_IMPORT_PASS`, отчёт `artifacts/reports/pedestrians-unity.txt`.
4. Просмотр `artifacts/visual-review/pedestrians/` и `unity-lineup.png`; Play Mode: пешеход, перемещаемый скриптом, идёт/бежит без скольжения.

## 4. Условия завершения
Пункты 1–3 PASS, пункт 4 проверен человеком в Unity.
