# T27 — Граф v2: городская семантика (City Semantics for RoadGraph v2)

- **Требования:** R07 (единый roadgraph), R09, R10, R15.
- **Критерий приёмки:** A07.
- **ADR:** ADR-002, ADR-003, ADR-011. Дизайн: [city.md](../city.md#что-добавляется-в-граф-v2-сверх-t11).
- **Зависит от:** T11 (базовый `WorldDocumentV2`).

## 1. Конкретный результат и зависимости

Расширить `WorldDocumentV2` данными, без которых город не работает, и научить валидатор их проверять:
- `LaneBoundary`: тип разметки между соседними полосами и по оси (`Solid`, `Dashed`, `DoubleSolid`, `SolidDashed`, `None`), участками по `s` вдоль полосы.
- `Lane.allowedManeuvers`: набор флагов `Straight | Right | Left | UTurn`.
- `SignPlacement`: `id`, код знака по ГОСТ Р 52290-2004 (строка, например `"3.24"`), значение (`"40"`), таблички, поза, `laneIds`, начало и конец зоны действия (`startS`, `endLaneId/endS` или «до ближайшего перекрёстка»).
- `JunctionApproach`: для каждого въезда на перекрёсток — `priority` (`Main`, `Secondary`, `Equal`, `Signalized`), ссылка на знаки-источники.
- `SidewalkPath` (полилиния, связи) и связь `PedestrianCrossing` ↔ тротуары ↔ пересекаемые `laneIds`.
- `Zone`: тип (`Parking`, `NoStopping`, `NoParking`, `KeepJunctionClear`), полигон или диапазон `s` на полосах.
- `SpawnPoint`: полоса или тротуар, `s`, роль (`Vehicle`, `Pedestrian`).

## 3. Точные входы, выходы и контракты

- Все новые сущности имеют стабильный строковый `id`; ссылки только по `id`.
- `WorldValidatorV2.Validate(WorldDocumentV2)` бросает `InvalidDataException` с `id` проблемного элемента.
- JsonUtility не сериализует словари и вложенные полиморфные типы — только массивы простых DTO и enum.

## 4. Примеры данных и ожидаемого поведения

- Полоса с `allowedManeuvers = Straight | Right` и связью налево на перекрёстке → ошибка валидации «связь не разрешена манёвром полосы».
- Знак `3.24` «40» на полосе `a:0` с концом зоны «до ближайшего перекрёстка» → валиден, зона вычисляется компилятором.
- Переход, ссылающийся на полосу, которую его полилиния не пересекает → ошибка.

## 5. Отрицательные сценарии

- Ссылка на несуществующую полосу, тротуар или знак → `InvalidDataException`.
- Участки `LaneBoundary` перекрываются или выходят за длину полосы → ошибка.
- Въезд с `priority = Main` без знака-источника 2.1/2.3.x → ошибка (главность задаётся знаком).
- Неизвестный код знака (нет в справочнике из T28) → ошибка, а не молчаливый пропуск.
