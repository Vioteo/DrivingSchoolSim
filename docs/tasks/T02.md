# T02 — Manifest и валидация импорта ассета (Asset Import Validation)

- **Требования:** R05 (автомобиль), R15 (доказуемость).
- **Критерий приёмки:** A02 (asset check, критерии G01–G08).
- **ADR:** ADR-010 (привязка к хешу), ADR-006 (технический стенд).

## 1. Конкретный результат и зависимости

Разработать редакторский валидатор импорта модели автомобиля в Unity (`AssetImportValidator`). Валидатор проверяет импортированный префаб `DS_Sedan_A.fbx` на соответствие стандарту `docs/asset-standard.md`:
- Пропорции и габариты кузова (G01): длина ~4.5м, ширина ~1.8м (2.25м с зеркалами), высота ~1.5м, колесная база ~2.72м, колея ~1.71м, радиус колес ~0.33м.
- Наличие и уникальность обязательных узлов: `Wheel_FL`, `Wheel_FR`, `Wheel_RL`, `Wheel_RR`, `SteeringWheel_Pivot`, `Pedal_Throttle`, `Pedal_Brake`, `Pedal_Clutch`, `Socket_DriverEye`, `Socket_CentreOfMass`, `MirrorSurface_L`, `MirrorSurface_R`, `MirrorSurface_Centre`, `Transmission_Manual`, `Transmission_Automatic`.
- Масштаб корневого и дочерних узлов (строго Vector3.one).
- Результат сохраняется в структурированный отчет `artifacts/reports/asset-import-check.json`.

## 2. Разрешённая область изменений

- `Assets/DrivingSchool/Code/Editor/AssetImportValidator.cs` (новый редакторский скрипт)
- `Assets/DrivingSchool/Code/Editor/ProjectBuilder.cs` (вызов валидатора при Prepare/Build)
- Файловый бюджет: ≤ 2 production files, 0 runtime code.

## 3. Точные входы, выходы и контракты

- **Входы:** `Assets/DrivingSchool/Art/DS_Sedan_A.fbx`, `Assets/StreamingAssets/Examples/vehicle.json`.
- **Выходы:** `artifacts/reports/asset-import-check.json` с SHA256 модели, датой, числом треугольников, списком материалов и статусами проверок G01–G08.
- **Контракт вызова:** Метод `DrivingSchool.Editor.AssetImportValidator.ValidateSedanAsset()`, вызываемый из командной строки и из Prepare.

## 5. Отрицательные сценарии

- **Отсутствующий сокет:** Если из модели удален `Socket_DriverEye`, проверка G04 возвращает `FAIL`, а отчет фиксирует `"requiredNodesMissing": ["Socket_DriverEye"]`.
- **Искаженный масштаб:** Если масштаб узла колеса `Wheel_FL` равен `(1.2, 1.2, 1.2)` или ось инвертирована, проверка G01 возвращает `FAIL` с сообщением `Non-uniform scale on child node Wheel_FL`.
- **Слитые педали:** Если все три педали представлены одним мешем вместо независимых объектов, проверка G06 возвращает `FAIL`.

## 6. Команда проверки и доказательства

```powershell

Get-Content artifacts/reports/asset-import-check.json | ConvertFrom-Json
```

## 7. Условия завершения

- Создан файл `artifacts/reports/asset-import-check.json`.
- Все обязательные имена узлов обнаружены в импортированном префабе `DS_Sedan_A`.
- В логе валидатора зафиксирован хеш FBX и статус `PASS`.
