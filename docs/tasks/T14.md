# T14 — Транзакционная команда редактора мира (Runtime Map Editor Command)

- **Требования:** R07 (единый граф), R08 (встроенный runtime-редактор без Editor API), R15 (доказуемость).
- **Критерий приёмки:** A09 (runtime editor command & undo/redo).
- **ADR:** ADR-003 (один roadgraph как источник истины), ADR-002 (версионирование).

## 1. Конкретный результат и зависимости

Разработать архитектуру транзакционных команд редактора карты в рантайме `WorldCommandService` и реализовать базовую команду `AddRoadSegmentCommand`:
- Работа в standalone сборке Windows Player (без использования неймспейса `UnityEditor` или `AssetDatabase`).
- Паттерн Command с полной поддержкой `Execute()`, `Undo()`, `Redo()`.
- Команда `AddRoadSegmentCommand`:
  - Создает начальный и конечный узлы `RoadNode` (или переиспользует существующие при привязке по snap-радиусу).
  - Создает `RoadSegment` с заданной шириной и скоростным лимитом.
  - Автоматически генерирует полосы движения `Lane` с корректными индексами (`-1` и `+1`) и направлениями.
- Валидация перед коммитом: если топология нарушена, транзакция откатывается без повреждения исходного графа.

## 3. Точные входы, выходы и контракты

- **Контракт команды:**
  ```csharp
  public interface IWorldEditorCommand
  {
      string Description { get; }
      bool Execute(WorldDocument document);
      void Undo(WorldDocument document);
  }

  public class WorldCommandService
  {
      public bool CanUndo { get; }
      public bool CanRedo { get; }
      public bool ExecuteCommand(IWorldEditorCommand command);
      public bool Undo();
      public bool Redo();
  }
  ```
- **Входы:** Начальная точка `(double x1, double z1)`, конечная точка `(double x2, double z2)`, ширина полосы, число полос.
- **Выходы:** Обновленный граф мира с новыми узлами и полосами.

## 4. Примеры данных и ожидаемого поведения

- Добавление дороги от `(0, 0, 0)` до `(0, 0, 50)` на 2 полосы:
  - Создаются узлы `node_01` и `node_02`.
  - Создается сегмент `seg_01` длиной 50 м.
  - Создаются полосы `lane_01_fwd` и `lane_01_bwd`.
  - `CanUndo` становится `true`.
- Вызов `Undo()`:
  - Узлы, сегмент и полосы удаляются из документа.
  - Граф идентичен состоянию до добавления дороги.
  - `CanRedo` становится `true`.
- Вызов `Redo()`:
  - Дорога восстанавливается со всеми связями.

## 5. Отрицательные сценарии

- **Нулевая длина дороги (`p1 == p2`):** Команда отклоняется валидатором до добавления в историю `Undo`, документ не модифицируется.
- **Попытка разорвать существующую полосу недопустимым изменением:** Если команда приводит к невалидному состоянию графа (например, повисший successor), метод возвращает `false`, а изменения отменяются.
- **Переполнение стека Undo:** Ограничение глубины истории команд (по умолчанию 50 действий) с корректным вытеснением старых шагов.

## 7. Условия завершения

- Сервис команд компилируется без использования `UnityEditor`.
- Тесты проверяют цикл `Execute → Undo → Redo` и целостность графа на каждом этапе.
- Ошибочные команды не загрязняют историю отмены.
