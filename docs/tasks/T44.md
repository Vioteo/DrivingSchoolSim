# T44 — Общественный транспорт: модели, трамвайные пути, остановки (Transit Kit v1)

- **Требования:** R09 (трафик: будущие автобусы и трамваи ИИ), R06 (городская среда). Только ассеты, без логики.
- **Приёмка:** чек-лист ассета `art-pipeline.md` §9; для машин — упрощённый G01/G03/G07 (габариты, коллизия, колёса в нейтрали).
- **Документ набора:** [transit-kit.md](../transit-kit.md).

## 1. Результат
Воспроизводимый набор `PT_*` из 11 моделей: городской автобус 12 м, маршрутка, односекционный трамвай; улица с трамвайными путями в одном уровне, обособленный путь на газоне (прямая и поворот R25); остановочный павильон, трамвайная посадочная площадка; знаки 5.16/5.17 (стилизовано); разметка 1.17 (стилизовано).

## 2. Разрешённая область изменений
- `tools/transit_kit/*`, `tools/build_transit.py`, `tools/build_transit.bat` (новые).
- `Assets/DrivingSchool/Art/Transit/*` (результат генератора), `ArtSource/DS_TransitKit.blend`.
- `Assets/DrivingSchool/Code/Editor/TransitKitBuilder.cs` (новый; создаёт `Materials/Transit`, `Prefabs/Transit`, `Scenes/Transit_Demo.unity`).
- Документы: `docs/transit-kit.md`, префикс в `docs/art-pipeline.md`, эта карточка.
- Отчёты: `artifacts/reports/transit-*.json|log`, `artifacts/visual-review/transit/`.
- Не трогать: `vehicle_kit`, существующие сцены, список сцен сборки, `Contracts`.

## 3. Контракты
- Оси и экспорт — `art-pipeline.md` §3–4: перёд −Y в Blender, FBX `-Z`/`Y`, `FBX_SCALE_UNITS`; `Socket_Front`/`Socket_Up` для проверки осей в Unity.
- Имена для кода: `Wheel_FL/FR/RL/RR`, `Socket_DriverEye`, `Socket_CentreOfMass`, `MirrorSurface_L/R`, `Door_<n>_<A|B>_Pivot`, `Door_Slide_Pivot`, `Bogie_F/R_Pivot`, `Wheelset_*`, `Pantograph_Pivot`, `Headlight_*`, `Taillight_*`, `Brake_*`, `Indicator_*`, `COL_*`, `Socket_Start/End`, `Socket_Tram_R/L_Start/End`.
- Путь: верх рельса = 0, центры головок ±0,7975 м от оси пути (как у переезда), центры путей ±1,75 м.
