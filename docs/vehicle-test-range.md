# Тестовый полигон автомобиля

Карточка: [T27](tasks/T27.md). Сцена `Assets/DrivingSchool/Scenes/VehicleTestRange.unity` не хранится руками — её собирает генератор.

## Как собрать и запустить

1. Открыть проект в Unity 6000.3.10f1.
2. Меню **Driving School → Vehicle Test Range → Build scene**. В консоли должно появиться `VEHICLE_TEST_RANGE_BUILD_PASS`, отчёт — `artifacts/reports/vehicle-test-range-build.json`.
   Пакетно: `& $u -batchmode -projectPath $p -executeMethod DrivingSchool.Editor.VehicleTestRangeBuilder.Build -quit -logFile "$p/artifacts/reports/vehicle-test-range-build.log"`.
3. Открыть сцену и нажать Play. Машина стоит в начале прямой, двигатель заглушён, ручник затянут.
4. **F8** — автоматическая самопроверка (≈40 с): результат в правой панели и в логе (`VEHICLE_SELFCHECK PASS/FAIL …`).

Сцена задаёт шаг физики 100 Гц (`Time.fixedDeltaTime = 0.01` при старте), настройки проекта не меняются.

## Схема полигона

```
                               дорога B (+X, 120 м)                 площадка 90×90 м
             ┌──────────────────────────────────────────────┐┌───────────────────────────┐
             │                                              ││  машина-препятствие  ▣    │
     поворот ╮                                              ││            блоки ▮▮▮▮▮     │
     R30, 90°│                                              ││  ░░ лёд 20×20 ░░           │
             │  z=180…228  слалом (5 конусов, шаг 12 м)     │└───────────────────────────┘
  дорога A   │  z=140      асфальтовая ИДН (2 × 3,5 м)
  (+Z,290 м) │  z=80       резиновый «лежачий» 7 м
             │  z=−20      СТАРТ (F9)
```

Фонари освещения стоят вдоль обеих дорог через 40 м.

## Управление

| Клавиши | Действие |
|---|---|
| I / Enter (удерживать) | зажигание / стартер. Стартер работает только при выжатом сцеплении или нейтрали (МКПП), в P/N (АКПП) |
| W / S, A / D (или стрелки) | газ / тормоз, руль |
| Shift (Ctrl) | сцепление (отпускается медленнее, чем выжимается) |
| Space | ручник (переключатель) |
| 1–6, R, N (0) | передачи МКПП; в АКПП 1–6 = D, R = R, N = N, **P** = паркинг |
| Q / E | левый / правый поворотник; выключается сам после поворота руля и возврата |
| X | аварийная сигнализация |
| L / K / J | габариты → ближний → выкл / дальний / «моргнуть» |
| H | звуковой сигнал |
| V / B | дворники: выкл → прерывистый → 1 → 2 / омыватель (3 взмаха) |
| T | ремень безопасности |
| C | камера: салон → сзади → облёт (ПКМ — вращать, колесо — дистанция) |
| ПКМ, Z или «,» / «.» | посмотреть по сторонам из салона; средняя кнопка мыши — назад |
| F1 / F2 / F3 | выбрать левое / салонное / правое зеркало |
| NumPad 8/2/4/6 (Home/End/Delete/PageDown), NumPad 5 | наклонить выбранное зеркало, сброс |
| F5 / F6 | следующая / предыдущая погода |
| F7 | МКПП ↔ АКПП (машина перезапускается заглушённой) |
| F8 | самопроверка |
| F9 / Backspace, F10 | на старт / к машине для столкновения |
| F4 | показать/скрыть подсказку |

## Что проверяет самопроверка (F8)

1. Пуск стартером при выжатом сцеплении; лампы аккумулятора и масла гаснут после запуска.
2. Габариты, ближний, дальний (синяя лампа на панели), найдены рассеиватели фар/фонарей/поворотников на модели.
3. Левый поворотник мигает 1,5 Гц, стрелка на панели загорается, правый не включается; аварийка.
4. Стоп-сигнал при нажатии тормоза.
5. Руль до упора = −450°, передние колёса поворачиваются, внутреннее колесо на больший угол.
6. Трогание на 1-й без заглохания, колёса вращаются, торможение до остановки.
7. Фонарь заднего хода на R.
8. Двигатель глохнет при броске сцепления, загорается Check Engine.
9. Ливень смачивает стекло, дворники убирают воду, мокрая дорога снижает сцепление, дворники паркуются, ночь.
10. Три зеркала рендерятся.
11. Разгон к припаркованной машине: удар фиксируется, машина-препятствие смещается.

Проверка использует тот же путь `DriverCommand → VehicleSolver → Rigidbody`, что и игрок, только ввод подаётся скриптом. Это не заменяет ручную приёмку: цвета, яркость, направление вращения стрелок и щёток, правильность отражений оценивает человек.

## Ручная приёмка

- [ ] Ночь (F5 до `ClearNight`): габариты, ближний и дальний различимы на дороге; дальний светит дальше и выше.
- [ ] Сзади (камера C): стоп-сигналы ярче габаритов, горит дополнительный верхний; фонарь ЗХ белый.
- [ ] Поворотники мигают спереди, сзади и в повторителях на зеркалах, слышны щелчки реле.
- [ ] Руль в салоне вращается в сторону поворота, колёса крутятся вперёд при движении вперёд, подвеска отрабатывает «лежачего».
- [ ] Стрелки идут по часовой стрелке, тахометр ≈ 850 об/мин на холостом ходу. Если стрелка идёт против часовой — поменять знак `needleDirection` у `VehicleVisuals` и сообщить.
- [ ] Контрольные лампы видны между шкалами; при необходимости подвинуть `DashboardView.rowOffset` (в генераторе, не в сцене).
- [ ] На МКПП: трогание без газа на холостом возможно при медленном отпускании сцепления; резкий бросок — заглох; на 3-й с места — заглох.
- [ ] На АКПП (F7): в D машина ползёт без газа, в P стоит, P на ходу не включается.
- [ ] Лёд: торможение и поворот заметно хуже, машина скользит.
- [ ] Дождь: капли на стекле копятся быстрее на скорости, щётки стирают их по своей дуге, в парковке щётки лежат внизу.
- [ ] Зеркала: отражение не зеркально перевёрнуто, в боковых видна своя машина, регулировка меняет вид.
- [ ] Удар в машину на площадке: она сдвигается, на HUD счётчик столкновений.

## Как это устроено

```
KeyboardInputSource ──DriverCommand──► VehicleController (FixedUpdate)
                                            │
                                   VehiclePhysicsAdapter ── 4 raycast → WheelContact[4]
                                            │
                                   VehicleSolver (DS.Simulation, чистый C#)
                                     EngineModel · ClutchModel/TorqueConverter · GearboxModel
                                     открытый дифференциал · TireModel · тормоза/ABS
                                     VehicleLightsModel · WiperModel
                                            │ силы шин, VehicleState
                                   Rigidbody.AddForceAtPosition
                                            │
        VehicleVisuals · VehicleLightsView · DashboardView · WindshieldRainView · VehicleMirrorRig
```

- Солвер не знает про Unity: получает скорости пятна контакта и нагрузки, возвращает силы. Внутри 20 подшагов на тик (0,5 мс) для вращения колёс и двигателя.
- Сцепление: ёмкость линейна по педали (1 = выжато, 0 Н·м; 0,5 = 120 Н·м). В замкнутом состоянии двигатель и ведущие колёса решаются как одна инерция; размыкание, когда требуемый момент превышает ёмкость. Отсюда естественное заглохание при броске сцепления.
- АКПП: гидротрансформатор (момент насоса ~ C·ω², умножение момента до 2,0 при остановке), блокировка ГТ со 2-й передачи, переключения по оборотам с порогами, зависящими от газа.
- Шины: продольное и боковое скольжение, круг трения μ·Fz, на малых скоростях знаменатель ограничен 3 м/с, а стоящая машина удерживается «якорем» статического трения (не сползает с уклона на ручнике).
- Для headless-тестов есть `PlanarChassis` (3 степени свободы); если `Rigidbody` кинематический, адаптер переключается на него.

## Ограничения и что дальше

- Калибровка игровая; нужна сверка с реальным учебным автомобилем (T07/T08: разгон, тормозной путь, обороты трогания).
- Модель седана экспортирована по старой схеме осей: генератор повторяет поворот `Euler(-90,180,0)` из `TrainingGroundBuilder`. Адаптер пишет ошибку в консоль, если `Wheel_FL` не оказался спереди слева.
- Рассеиватели ищутся по материалам `Lamp_White/Red/Amber` и именам; у текущего FBX нет отдельной геометрии фонаря заднего хода — роль «задний ход» получат белые задние линзы, если они есть, иначе светит только источник света.
- Контрольные лампы и индикатор передачи — процедурные квадраты; позиция подбирается по `GaugeFace_*`/`Gear_Display`.
- Нет звука двигателя, сетевого/VR-режима, FFB.
