# Знаки и светофоры — Traffic Kit v1

Набор из 32 моделей: 18 знаков и готовых сочетаний, 11 дополнительных табличек, 3 светофора. Графика стилизована; это игровые ассеты, не нормативные чертежи.

Основные знаки: STOP, уступите дорогу, главная дорога, ограничения 30/40/60, въезд запрещён, пешеходный переход, парковка, прямо, направо, круговое движение, остановка запрещена, стоянка запрещена. Въезд и выезд из населённого пункта — белые щиты «ЛЕСНОЙ» на двух стойках, выезд перечёркнут красной полосой. Надпись задаётся константой `TOWN` в генераторе.

Дополнительные таблички доступны отдельно в `DS_Plaque_*`:

- `Distance100`, `Distance300`: расстояние до объекта 100 и 300 м.
- `Zone100`: протяжённость зоны действия 100 м со стрелкой вверх.
- `ZoneStart`, `ZoneEnd`, `ZoneContinue`: вверх, вниз, вверх/вниз.
- `DirectionLeft`, `DirectionRight`, `DirectionBoth`: налево, направо, в обе стороны.
- `ZoneLeft100`, `ZoneRight100`: протяжённость 100 м в указанную сторону.

Готовые сочетания на одной стойке: `DS_Sign_NoStopping_Zone100`, `DS_Sign_NoParking_ZoneEnd`. Три светофора: транспортный трёхсекционный, с дополнительной стрелкой направо, пешеходный.

## Использование в Unity

Откройте `Assets/DrivingSchool/Scenes/TrafficShowroom.unity` для общего просмотра. Перетащите нужный prefab из `Assets/DrivingSchool/Prefabs/Traffic` в свою сцену. Корень имеет единичный масштаб, pivot на земле, Y вверх, лицевая сторона +Z. Стойки высотой 2,75 м у знаков и 3,35 м у светофоров. На стойках стоят CapsuleCollider, на отдельных щитах и секциях корпуса — BoxCollider; зазор между знаком и табличкой сохраняется. Вложенный `Model` содержит конверсию осей FBX: не обнуляйте его поворот отдельно от корня.

Отдельная табличка имеет размеры 0,64 × 0,36 м и pivot посередине нижней кромки, без собственной стойки. Чтобы добавить её к знаку, сделайте её дочерним объектом корня prefab, задайте local rotation 0 и local position `(0, 1.65, 0)`: центр таблички окажется на высоте 1,83 м. Можно располагать несколько табличек одна под другой с шагом 0,40 м.

Светофоры стартуют с красным сигналом. На компоненте `TrafficSignalView` доступны `Aspect` и `Arrow`; изменения видны и в редакторе. Из кода:

```csharp
using DrivingSchool.Presentation;

signal.SetAspect(TrafficSignalView.Aspect.Green);
signal.SetAspect(TrafficSignalView.Aspect.Red, additionalArrow: true);
signal.SetAspect(TrafficSignalView.Aspect.Off);
```

Доступные состояния: Off, Red, RedAmber, Amber, Green. Пешеходный вариант поддерживает Off, Red, Green; недопустимый жёлтый сигнал отклоняется. Дополнительная стрелка переключается независимо. Компонент управляет видимостью светящихся поверхностей; тёмные линзы, козырьки и корпус остаются видимыми. Таймеры перекрёстка, приоритет движения и правила ПДД подключаются отдельно через `SetAspect`.

## Исходники и повторная сборка

- `ArtSource/DS_TrafficKit.blend` — редактируемый набор, с отдельными деталями, материалами и осмысленными именами.
- `Assets/DrivingSchool/Art/Traffic/*.fbx` — 32 отдельные модели в метрах.
- `artifacts/visual-review/traffic/models/*.glb` — обменные модели для просмотра; включают геометрию всех светящихся элементов, без Unity-контроллера состояний.
- `Assets/DrivingSchool/Materials/Traffic` — общие материалы URP.
- `tools/build_traffic_assets.py` — воспроизводимый генератор Blender 5, без текстур; кириллица строится системным Arial Bold Windows и переводится в mesh, шрифтовые файлы для использования моделей не нужны.
- `artifacts/reports/traffic-manifest.json` — SHA256, размеры, треугольники, материалы каждого экспорта и hash исходника.
- `artifacts/reports/traffic-unity-check.txt` — результат импорта и проверок Unity.

Из корня проекта: `blender -b --python tools/build_traffic_assets.py`. После экспорта выполните меню Unity **Driving School → Traffic → Build prefabs and showroom**. Команда обновляет только выделенные модели/префабы и `TrafficShowroom`, не запускает общую подготовку проекта. Для batch: `-executeMethod DrivingSchool.Editor.TrafficAssetBuilder.Build`. Для снимка Unity: `-executeMethod DrivingSchool.Editor.TrafficAssetBuilder.Capture` с графическим устройством, без `-nographics`.

LOD пока не подготовлены. Геометрия креплений сохранена для просмотра вблизи; показатели массовой расстановки и VR не измерялись. Существующие сцены District/Autodrome/Showroom и список сцен сборки не изменяются этим генератором.
