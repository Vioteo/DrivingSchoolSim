# Требования и трассировка

Приоритет MUST означает обязательство конечного продукта; это не заявление, что всё входит в текущий этап. Этап M0: модель, визуальные прототипы UI, архитектура, воспроизводимая передача. M1: локальная учебная поездка. M2: мир/трафик/обучение. M3: аппаратная проверка и производительность. Указанные карточки являются последовательными заготовками работ; одна карточка не заменяет интеграционную приёмку.

- **R01 MUST, M0/M1 — платформа.** Windows x64, Unity6000.3.10f1, URP, Input System, uGUI/TMP, OpenXR. Задачи T01, T03, T24. Приёмка A01, A03, A14. Сейчас пакеты и editor builder подготовлены, UI IMGUI.
- **R02 MUST, M1/M3 — ввод.** Клавиатура; G27 руль, три независимые педали, H-pattern МКПП, сохранение калибровки, disconnect/focus loss. Задачи T04, T05. Приёмка A04. Сейчас только IInputSource.
- **R03 MUST, M1/M3 — FFB.** Нормализованный ограниченный момент, безопасное обнуление на pause/focus loss/disconnect/dispose, явный статус недоступности. Задача T06. Приёмка A05. Сейчас только интерфейс.
- **R04 MUST, M1 — учебная динамика.** Engine phases, запуск/заглохание, сцепление, передача момента, МКПП и АКПП, тормоза/ручник, подвеска, шины и устойчивое интегрирование. Задачи T07–T10. Приёмка A06. Формулы не считаются solver или реализмом; калибровка по данным обязательна.
- **R05 MUST, M0/M1 — автомобиль.** Кузов/салон, три зеркала, читаемые приборы, отдельные pedals/pivots, коллизии, нейтральное положение и полный ход колёс, ручной/автоматический варианты. Задачи T02, T10, T23. Приёмка A02, A13. Арт имеет отдельного исполнителя.
- **R06 MUST, M2 — территория.** 10 000 × 10 000 м город/пригород, районы, 256-м чанки, загрузка/выгрузка, перенос начала координат без потери точности. Задачи T12, T13. Приёмка A08. Masterplan не построенный мир.
- **R07 MUST, M2 — единый roadgraph.** Геометрия, полосы, successor connections и управляющие элементы служат общей моделью для mesh, маршрутов, правил и runtime editor. Задачи T11, T14. Приёмка A07, A09. v1 ограничен прямой топологией.
- **R08 MUST, M2 — runtime editor.** Сетка, прямые/кривые, полосы, catalog placements, undo/redo и сохранение/загрузка без Editor API. Задачи T14, T15. Приёмка A09, A10.
- **R09 MUST, M2 — трафик и пешеходы.** Машины следуют тем же полосам, учитывают сигналы/приоритет; пешеходы пересекают дорогу по связи с graph, встречаются с машиной физически/логически. Задачи T16, T17. Приёмка A11.
- **R10 MUST, M2 — правила.** Версионированные проверяемые правила и объяснимые события с evidence, штрафами и участниками. Задача T18. Приёмка A12. Объём правил расширяется по одному семейству за карточку.
- **R11 MUST, M2 — погода и зима.** Dry/wet/snow/ice параметры покрытия влияют на сцепление; снег/осадки/видимость согласованы с физикой и UI. Задача T19. Приёмка A15. Значения — калибруемые, а не «истинные» коэффициенты.
- **R12 MUST, M1/M2 — восемь занятий.** Версионированные определения, briefing, цели, ошибка/успех, отмена, повтор и итоги с ассистами/evidence. Задачи T20, T21. Приёмка A16. Набор площадки ниже соответствует EXERCISES в tools/build_art.py.
- **R13 MUST, M2 — теория.** Версия контента, источник, объяснения, темы; официальные билеты только из подтверждённого внешнего контента с правом использования. Задача T22. Приёмка A17. Текущий пример авторский, isOfficial=false; не выдавать его за экзаменационный.
- **R14 MUST, M3 — производительность.** Ryzen2700X / RTX2080 / RAM32GB: Windows 1920 × 1080, целевые 60fps на согласованном качестве, включая движение/стриминг и три зеркала. Задача T25. Приёмка A18. Для PCVR отдельный профиль частоты и разрешения конкретного HMD, не переносить desktop60fps.
- **R15 MUST, M0–M3 — доказуемость.** Имена, единицы, исходники/экспорты, статусы и результаты привязаны к ревизии; noEngineReferences сохраняются, совместимость данных явная. Задачи T01, T02, T11, T15, T26. Приёмка A01, A02, A07, A10, A19.

## Восемь учебных упражнений площадки

Это внутренние учебные сценарии, не утверждение о действующем официальном экзамене: `startstop` — старт/остановка; `slalom` — змейка; `boxpark` — въезд в бокс; `parallel` — параллельная парковка; `hill` — начало движения на подъёме; `uturn` — разворот; `reverse` — движение задним ходом; `shiftbrake` — переключение передач и торможение. Городской маршрут — отдельный сценарий. Длины, допуски, таймеры, штрафы и юрисдикция должны храниться в конкретной версии контента. Не придумывать правовые нормы ради заполнения примера.

Из M0 исключена претензия на готовый симулятор/сертифицированное обучение. M0 закрывается архитектурой, проверяемыми арт-артефактами и UI-макетом с честной маркировкой. Геометрическая приёмка ассета и UI-прототип не закрывают M1–M3.
